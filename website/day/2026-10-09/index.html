Day in brief

Key rotation reaches general availability while baseline enforcement guidance adds a Graph query

The strongest changes affect trust authentication, Conditional Access scoping, and Agent ID troubleshooting. Updated What's New guidance describes key rotation for incoming trust referral flows as generally available, improving reliability and addressing failures when referral tickets use a secondary key. Enforcement Resource Exclusions guidance records that baseline-scope enforcement rollout began June 15, 2026, and adds a Microsoft Graph query. New Agent ID how-to articles cover autonomous and interactive sign-ins, while a separate Kerberos trust guide details setup and lifecycle operations. The standalone Kerberos Server Key Rotation article was removed, and access-package guidance now clarifies a limitation on overlapping automatic-assignment policies.

  • Entra ID · Authentication
    Generally available key rotation addresses secondary-key referral failures

    The updated What's New guidance says key rotation for incoming trust referral flows is generally available. It describes the change as improving reliability and addressing authentication failures caused when referral tickets use a secondary key; no required administrator action is stated.

  • Entra ID · Conditional Access
    Baseline enforcement rollout gains a policy-discovery query

    Enforcement Resource Exclusions guidance now states that baseline-scope enforcement rollout began June 15, 2026. It adds a Microsoft Graph query for finding affected Conditional Access policies and clarifies customization and sign-in review guidance.

  • Agent ID · Authentication
    Autonomous Agent ID sign-ins get preview health-investigation guidance

    A new how-to explains Health Monitoring signals and alerts, impact criteria, log correlation, troubleshooting, and prerequisites for autonomous agent sign-ins. The monitoring and alerts are documented as being in preview, with guidance for identifying affected applications and investigating application-only authentication failures.

  • Entra ID · Authentication
    Kerberos trust guidance covers setup through trust removal

    The new guide documents prerequisites, PowerShell module installation, Trusted Domain Object creation, client ticket configuration, key rotation, trust removal, and required permissions for managing trust between Microsoft Entra ID and on-premises AD DS.

  • ID Governance · Governance
    Automatic assignment policies must not overlap for matched users

    Entitlement Management guidance now clarifies that multiple automatic assignment policies for one access package are supported only when users do not match multiple policies simultaneously. Administrators should review overlapping policy scopes to avoid duplicate assignment paths.
