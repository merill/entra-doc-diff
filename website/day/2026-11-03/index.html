Day in brief

Microsoft-provided SMS and voice SSPR retirement sets February 2027 recovery deadline

Two Message Center notices carry the day’s main operational weight: Microsoft-provided SMS and voice authentication for self-service password reset begins retiring in February 2027, with a 50-day transition for each user group, while the Microsoft Entra Security Operator mapping in Defender for Office 365 changes starting December 2026. A new Private Access sign-in-every-time preview adds a Conditional Access-dependent reauthentication path. Most other entries are documentation maintenance or troubleshooting guidance, with notable Salesforce provisioning prerequisites and an RHEL upgrade warning.

  • Entra ID · Conditional Access
    SMS and voice SSPR authentication begins retiring in February 2027

    Microsoft-provided SMS and voice authentication for self-service password reset will retire beginning in February 2027. Each user group receives a 50-day transition, after which those methods will no longer be available for SSPR.

  • Entra ID · Security
    Defender for Office 365 removes default Security Operator permissions

    Starting in December 2026, the Unified RBAC mapping for the Microsoft Entra Security Operator role will remove default access to email threat policies and the Tenant/Allow Block List. Administrators must manually assign permissions if continued access is needed.

  • Private Access · Conditional Access
    Private Access sign-in-every-time preview gets a pilot deployment guide

    The new guide explains how to configure, test, and deploy reauthentication for selected private applications using one Conditional Access policy and a pilot group. It requires Global Secure Access Windows client version 2.34.222 or later.

  • Entra ID · Provisioning
    Salesforce provisioning guidance adds SOAP login and API-auth prerequisites

    The updated Entra provisioning tutorial requires Salesforce SOAP API `login()` to be enabled and the Admin Username account to have **Use Any API Auth**. It also documents Salesforce’s December 1, 2026 requirement and related credential-validation failures.

  • Entra ID · Authentication
    RHEL upgrades can remove the Entra SSH sign-in extension

    The Linux sign-in guidance now warns that in-place upgrades from RHEL 8.x to 9.x can remove the `aadsshlogin` package and cause `Permission denied (publickey)` errors. The documented remedy is to uninstall and reinstall the AADSSHLoginForLinux extension.
