Day in brief

1 April was documentation-heavy, but Agent ID and Account Discovery preview guidance—and a concrete SCIM clarification—stand out

All 20 recorded items are Microsoft Learn updates: there were no new or removed entries and no Message Center item. This was primarily documentation maintenance, including endpoint and schema tables, a Native Authentication table row, an MFA footnote, and author or metadata edits. The clearest substantive exceptions were updated guidance for the explicitly preview-labeled Agent ID Manage Agents and Entra ID Account Discovery capabilities, along with Agent ID setup and security guidance and the documented consequence of disabling SCIM. The sole Global Secure Access entry is summarized only by an author field. Nothing supplied establishes general availability, a retirement, or a service-wide behavior change.

  • Agent ID · General
    Agent ID Manage Agents: preview documentation describes owner and sponsor controls

    The updated page describes a preview end-user experience for viewing and controlling agent identities that a user owns or sponsors. It covers reviewing details, enabling or disabling agents, and requesting access. This documents the intended control model but does not establish general availability.

  • Entra ID · Governance
    Account Discovery is documented as a preview provisioning-governance workflow

    The updated Entra ID guidance covers finding and categorizing existing accounts in target applications, matching them to Microsoft Entra ID users, and preparing for provisioning governance. The entry remains explicitly preview-labeled, with no evidence of general availability or a change to current provisioning configurations.

  • Entra ID · Standards
    SCIM disable guidance states the tenant-wide API consequence

    The updated Disable SCIM API instructions say that, after confirmation and once the feature is turned off, all SCIM API calls to the tenant return an error and billing stops. This is a material runbook clarification for provisioning administrators; the record does not say that the behavior changed on 1 April.

  • Agent ID · General
    Agent ID AI-guided setup lists concrete validation prerequisites

    The updated setup guidance says the workflow validates that Frontier is enabled, checks Microsoft Entra roles, and verifies that PowerShell 7 or later and the Microsoft Graph beta module are installed. These are useful environment checks for teams evaluating the setup path, but the record does not establish a new launch or availability change.

  • Agent ID · Fundamentals
    Agent ID security guidance highlights external exposure

    The updated Security for AI overview identifies interactions with external users, third-party systems, and the public internet as exposure paths that could allow adversaries to compromise agents and reach organizational systems. This is security guidance and risk context, not a reported incident or a newly announced control.
