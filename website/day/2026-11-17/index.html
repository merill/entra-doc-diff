Day in brief

Identity verification guidance now spans risk remediation, onboarding, and account recovery

The strongest administrator signal is a coordinated identity-verification guidance set. A new Conditional Access guide covers resource access, onboarding, account recovery, and risk scenarios, while ID Protection guidance documents the Require Identity Verification preview control for User risk and Sign-in risk. A separate Entra ID update records that the earlier memberOf preview ended on November 3, 2026, leaving dependent configurations at their last known state. Authentication-methods guidance adds concrete policy limits, and Agent ID documents a tightly bounded Client ID Metadata Document preview.

  • Entra ID · Conditional Access
    Conditional Access guide maps identity verification across administrator journeys

    New Entra ID guidance explains how to configure and test identity verification for resource access, onboarding, account recovery, and risk-based scenarios. It includes prerequisites, eligible profiles, pilot setup, emergency-access exclusions, and policy ordering.

  • ID Protection · Conditional Access
    Risk-policy guidance details Require Identity Verification as a preview control

    Updated ID Protection guidance covers the Require Identity Verification control for User risk and Sign-in risk conditions. The control requires an eligible identity verification profile and supported credential; successful verification remediates the applicable risk, while failed verification does not.

  • Entra ID · General
    Retired memberOf preview leaves affected configurations frozen

    The earlier memberOf preview ended on November 3, 2026. Dynamic groups, dynamic administrative units, and entitlement management auto-assignment policies using it no longer update and remain in their last known state; the guidance directs administrators to MemberOf Next.

  • Entra ID · Authentication
    Authentication methods guidance documents a 20 KB policy limit

    Updated Entra ID guidance describes removal of individual-user targeting and a 20 KB policy-size limit. It also adds preview detail about passkey credential assurance and provenance, identity-verification history, and the possibility of registration or policy-save failures for policies targeting individual users or many groups.

  • Agent ID · Standards
    Agent ID documents public-metadata client IDs for delegated token requests

    A new preview guide explains how a public HTTPS Client ID Metadata Document URL can serve as an OAuth or MCP client ID for requesting delegated Microsoft Entra tokens without prior registration. The pattern requires authorization code flow with PKCE, may require administrator consent, has no service-level agreement, and is not recommended for production workloads.
