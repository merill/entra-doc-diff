Day in brief

Deprecated memberOf processing leaves groups stale as MemberOf Next becomes the migration path

The earlier memberOf preview ended on November 3, 2026: configurations using it stop updating and remain in their last known state. Microsoft’s documented route forward is MemberOf Next, alongside the preview of Transitive Reports To; both require Microsoft Entra ID Governance, Standard priority, and scheduled twice-daily processing. The period also brings risk-based CAPTCHA for SMS and voice MFA, preview coverage for the Windows App desktop client in Conditional Access app protection, and refreshed FIDO2 attestation data.

  • Entra ID · General
    The earlier memberOf preview has stopped updating configurations

    Microsoft states that the earlier memberOf preview ended on November 3, 2026. Configurations using it stop updating and remain in their last known state; guidance directs administrators to migrate affected dynamic groups, administrative units, and entitlement management auto-assignment policies to MemberOf Next.

  • Entra ID · Monitoring
    MemberOf Next and Transitive Reports To are documented in preview

    MemberOf Next flattens members from selected groups, while Transitive Reports To includes a manager’s full reporting hierarchy. Both support dynamic groups and administrative units and can scope governance controls. They require Microsoft Entra ID Governance, Standard priority, and scheduled twice-daily updates, so membership changes may not appear immediately.

  • Entra ID · Authentication
    Risk-based CAPTCHA is being added to SMS and voice MFA

    Starting in mid-November 2026, Microsoft Entra ID will add risk-based CAPTCHA verification to SMS and voice MFA to counter automated fraud. Some users may need to complete CAPTCHA before receiving codes or calls, requiring help-desk preparation, user communications, network readiness, and continued adoption of phishing-resistant methods.

  • Entra ID · Conditional Access
    Windows App desktop client joins Windows MAM preview guidance

    Conditional Access guidance now includes the Windows App desktop client as a preview target for Windows MAM and app protection policies, with links to configuration requirements and supported scenarios. Administrators evaluating the capability should review those requirements and environments before configuring policies.

  • Entra ID · Authentication
    FIDO2 attestation data adds 18 security-key models

    The attestation table now references MDS version 297 instead of 285 and adds 18 FIDO2 security-key models with their AAGUIDs and capability indicators. The refreshed list supports eligibility and capability checks when evaluating keys.
