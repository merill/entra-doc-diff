Day in brief

Entra Connect’s domain-join prerequisite is the clearest operational update; the rest is documentation maintenance

26 February 2026 was a quiet Microsoft Entra documentation day. The updated Entra Connect prerequisites explicitly state that Microsoft Entra Connect must be installed on a domain-joined server. Other targeted edits cover guest-user licensing, Quick Access licensing references, and device-identity export controls. All supplied items are documentation updates: there are no new, removed, or Message Center entries, and the evidence does not support calling any item a feature launch, preview, general-availability milestone, retirement, or security advisory.

  • Entra ID · General
    Microsoft Entra Connect prerequisite is explicitly documented

    The updated Connect Install Prerequisites page states that Microsoft Entra Connect must be installed on a domain-joined server. This is an operational prerequisite or documentation clarification, not evidence of a new Connect capability or changed service behavior. For a new installation, check the target server’s domain-join status; the evidence does not indicate that existing deployments must be changed.

  • ID Governance · Governance
    Guest-user licensing guidance was updated

    The Microsoft Entra ID Governance Licensing for Guest Users page was updated to explain how Microsoft Entra ID is licensed for guest users. The supplied summary gives no specific entitlement, pricing, or policy change, so this should be treated as refreshed guidance rather than a licensing announcement.

  • Entra ID · Fundamentals
    Configure Security documentation includes a Quick Access licensing reference

    The updated Configure Security content includes a reference for Quick Access user or group assignments alongside the Microsoft Entra Suite Add-on for Microsoft Entra ID P2. This supports using the page when checking licensing documentation, but the evidence does not establish a new entitlement or change to assignment behavior.

  • Entra ID · General
    Device identity export-column controls were clarified

    The Manage Device Identities update explains that administrators can use Manage view > Columns to choose which columns are displayed and exported. This is a portal/documentation usability clarification; no change to device identity, access, or security behavior is stated.
