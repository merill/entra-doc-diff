Day in brief

9 April 2026: a preview security capability and reference updates, with no rollout or retirement evidenced

All four supplied changes are updates to Microsoft Learn pages rather than new or removed items. The most substantive are documentation for Global Secure Access prompt-injection protection, explicitly marked preview, and an Entra ID optional-claims reference update covering the `acrs` claim. The External ID change is a partner-listing update, while the Continuous Access Evaluation entry contains only `- has-adal-ref`, indicating a likely mechanical reference edit. The evidence does not establish general availability, tenant-wide rollout, retirement, or a required configuration change.

  • Global Secure Access · Security
    Global Secure Access documents prompt-injection protection as a preview

    The updated page describes using Microsoft’s AI Gateway prompt-injection protection to protect enterprise generative AI apps. It is explicitly labeled preview; the supplied evidence does not establish general availability, deployment scope, or a required administrator change.

  • Entra ID · Authentication
    Entra ID optional-claims reference clarifies the `acrs` claim

    The reference describes `acrs` as a Microsoft Entra ID JWT claim containing Auth Context IDs. It says these IDs indicate which operations the bearer is eligible to perform, can be used to trigger step-up authentication from an application or service, and are often used with `xms_cc`. This is reference clarification, not evidence of a new rollout.

  • External ID · General
    External ID partner documentation adds a Grit Software listing

    The Services Integration Partners page lists Grit Software and describes its service for Azure AD B2C-to-Microsoft Entra External ID migrations, including the vendor’s statement that customer data is not sent to the underlying AI models. The supplied change is partner-directory content and does not evidence a change to External ID migration behavior.
