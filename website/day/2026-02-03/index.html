Day in brief

Documentation-focused day: Entra ID security and SAML guidance sharpened, while an ADAL-to-MSAL page was removed

3 February was primarily a Microsoft Learn maintenance day, with no new items or Message Center notices in the supplied record. The most consequential content consists of an Entra ID Recommendations entry for a preview GPO privilege-risk condition, clearer SAML ID requirements, and an ID Governance scenario for generating ServiceNow tickets during manual provisioning. The ADAL-to-MSAL recommendation page was removed, but the evidence does not establish that the migration recommendation or product support status was retired. No supplied item supports calling this a feature launch, general-availability event, or tenant-wide behavior change.

  • Entra ID · Fundamentals
    Entra ID Recommendations includes a preview GPO privilege-risk entry

    The updated Recommendations page identifies the case where a Group Policy Object assigns unprivileged identities to local groups with elevated privileges. The supplied row includes “Users” and is marked “Preview,” making this security guidance rather than evidence that a new detection or enforcement control was deployed.

  • Entra ID · Standards
    SAML documentation clarifies the required ID handling

    The Single Sign On SAML Protocol guidance states that ID is required, that Microsoft Entra ID uses it to populate InResponseTo, and that ID must not begin with a number. It gives prefixing a GUID with a string such as “ID” as a common strategy. This is an implementation clarification, not evidence of changed protocol behavior.

  • ID Governance · Governance
    Entitlement Management documents a ServiceNow ticketing workflow

    The updated Ticketed Provisioning scenario shows how custom extensibility and a Logic App can automatically generate ServiceNow tickets when users receive assignments but still need manual provisioning for application access. It documents an automation pattern rather than announcing native ticketed provisioning or a new availability tier.

  • Entra ID · Microsoft identity platform
    The ADAL-to-MSAL recommendation page was removed

    A Microsoft Entra documentation page titled “Recommendation Migrate From Adal To Msal” was removed. The supplied evidence does not say whether the content moved, was superseded, or whether ADAL/MSAL support status changed, so this should be treated as documentation removal—not proof that the migration recommendation itself was retired.
