Day in brief

Entitlement Management access-package discovery is scoped, while Agent Optimization documentation flags SCU consumption

22 July was primarily a documentation-maintenance day: all 80 recorded items were updates, with no new or removed entries and no Message Center items. The clearest substantive signals are a scoped access-package visibility change in ID Governance and a consumption clarification for Agent ID. The other supplied updates cover security defaults, Conditional Access, SSPR, staged rollout, and related guidance, but do not establish a new feature launch, GA release, retirement, or tenant-wide policy change.

  • ID Governance · Governance
    Entitlement Management access-package visibility change is limited to request discovery

    The updated guidance describes a visibility change affecting how end users find requestable access packages through the My Access Available tab, the View all option, and search within those sections. It does not change visibility logic for Suggested, Active, or Expired, and does not affect Request history or Approvals. Administrators should validate user-facing discovery expectations without assuming a broader My Access change.

  • Agent ID · General
    Agent Optimization action steps consume SCUs

    The updated Agent ID guidance states that when the agent identifies something that was not previously suggested, its follow-on action steps consume SCUs. This is a documentation clarification about resource consumption, not evidence of a new launch or a change to quotas or pricing.
