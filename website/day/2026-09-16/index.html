Day in brief

Microsoft-provided SMS and voice authentication face phased 2027 retirement deadlines

The strongest Entra guidance this period sets a February 1, 2027 retirement for Microsoft-provided SMS and voice authentication for users including internal guests, with Global Administrators and external users on July 1, 2027. Users relying only on those methods will receive a blocking passkey-registration prompt after their applicable deadline. Microsoft also added practical Cloud Sync migration and Connect Sync passwordless sign-in procedures, while most remaining activity involved Connect release-history, navigation, and command-path cleanup.

  • Entra ID · Authentication
    Phased retirement guidance gives SMS and voice two deadlines

    The authentication guidance states that Microsoft-provided SMS and voice retire February 1, 2027, for users including internal guests. Global Administrators and external users follow July 1, 2027; after the applicable date, users whose only MFA method is SMS or voice receive a blocking passkey-registration prompt. Administrators should move them to phishing-resistant methods or configure a customer-managed telecom provider where needed.

  • Entra ID · General
    Connect version guidance now identifies 2.6.91.0 as latest

    The version history replaces references to 2.6.90.0 with 2.6.91.0 and identifies 2.6.91.0 as the latest available version. Upgrades involving an existing ADSync database should use 2.6.91.0 or later, while installations of recalled version 2.6.79.0 should be uninstalled and replaced with 2.6.91.0.

  • Entra ID · Provisioning
    Cloud Sync migration guidance documents staged assessment and validation

    A new article covers using the guided migration tool to assess an environment, create Cloud Sync configurations, run a preactivation check, and validate synchronization after migration. It also identifies required roles, credentials, eligibility limits, supported scenarios, and a two-week validation process.

  • Entra ID · Authentication
    Connect Sync gets a documented FIDO2 and passkey sign-in path

    A new how-to explains how to enable FIDO2 and passkey methods, register credentials, configure a registry setting, and sign into Microsoft Entra Connect Sync without a password. The procedure gives administrators a documented passwordless setup path for synchronization installations and configuration.

  • Entra ID · Authentication
    Windows SSPR guidance moves from OMA-URI to Settings Catalog

    The revised procedure replaces the custom OMA-URI profile process with an Intune Settings Catalog policy. Administrators now select Authentication > Allow Aad Password Reset and set the value to Allow.
