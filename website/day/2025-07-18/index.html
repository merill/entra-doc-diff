Day in brief

Connect Sync V1 decommissioning guidance and new Workload ID isolation-scope documentation are the substantive items in an otherwise documentation-heavy day.

The strongest operational signal is an updated Microsoft Entra Connect Sync V1 page covering decommissioning and migration to V2. Workload ID also received new concept and configuration guidance for isolation scope on user-assigned managed identities. Microsoft Entra pass-through authentication saw a broad documentation refresh, while Microsoft Entra Private Access guidance for Active Directory domain controllers remains explicitly marked preview. The supplied records do not establish a new feature launch, GA transition, retirement deadline, or changed sign-in behavior.

  • Entra ID · General
    Microsoft Entra Connect Sync V1 decommissioning guidance was updated

    The revised page covers Azure AD Connect V1 decommissioning and migration to V2. This is retirement and migration guidance, not evidence that a new cutoff date or service behavior change was announced on 18 July; the record provides no deadline.

  • Workload ID · Security

    A new configuration article explains how to configure isolation scope, with a companion concept article describing its intended security and resilience benefits. These are new documentation entries, but the evidence does not identify preview or GA status, defaults, or a mandatory rollout.

  • Entra ID · Authentication
    Microsoft Entra pass-through authentication guidance was broadly refreshed

    The updated PTA material spans current limitations, how PTA works, quickstart, troubleshooting, security, release history, disabling PTA, and authentication-agent upgrades. The agent-upgrade guide is explicitly labeled preview. The supplied summaries do not describe a new agent release, changed authentication behavior, or GA announcement, so this is best treated as documentation maintenance.

  • Private Access · General
    Private Access preview configuration guidance for Active Directory domain controllers was updated

    The updated Microsoft Entra Private Access page covers configuring access for Active Directory domain controllers and retains “(preview)” in its title. The record supports a documentation update only, not a GA transition or a newly described capability.
