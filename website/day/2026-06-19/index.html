Day in brief

Agent ID documentation flags a coming Agent 365 requirement for agent protection; External ID adds Android fraud-SDK header guidance

19 June's meaningful changes are mostly documentation updates rather than announced service launches. The clearest licensing change is the Agent ID guidance that ID Protection for agents will require a Microsoft Agent 365 license starting soon. A new External ID article covers custom x-* headers for native authentication requests in Android (Kotlin), while updated Entra ID material describes a bulk-operations experience explicitly marked Preview and clarifies that Connect staged-rollout group edits can take up to 24 hours to apply. The supplied evidence indicates no retirement or general-availability announcement.

  • Agent ID · Security
    ID Protection for agents gains a stated licensing requirement

    Updated Agent ID licensing guidance says ID Protection for agents will require a Microsoft Agent 365 license starting soon to extend protection through Microsoft Entra Agent ID. This is a forthcoming licensing requirement in the documentation, not a reported general-availability launch or retirement, and no effective date is supplied.

  • External ID · Authentication
    External ID adds Android/Kotlin custom-header integration guidance

    A new Microsoft Learn article explains how an Android (Kotlin) app can attach custom x-* headers to native authentication network requests so fraud-detection SDKs can integrate with Microsoft Entra External ID. The evidence establishes new implementation guidance, not a tenant-side setting or a service-availability change.

  • Entra ID · Fundamentals
    Bulk operations experience is documented as Preview

    The updated Microsoft Entra bulk-operations article describes a new experience for managing users, groups, and devices and labels it Preview. Same-day updates cover CSV-based bulk add and remove operations and bulk group-membership download, but the supplied evidence does not establish general availability or a rollout date.

  • Entra ID · General
    Connect staged-rollout group edits may take up to 24 hours

    Updated Connect staged rollout guidance says adding or removing users in a staged-rollout group can take up to 24 hours to take effect. This is an operational timing clarification in the documentation, not evidence of a new rollout feature or an immediate propagation guarantee.

  • Entra ID · Conditional Access
    Conditional Access licensing coverage is spelled out for Entra Suite and Microsoft 365 E7

    The updated Conditional Access licensing page states that Microsoft Entra Suite includes all Microsoft Entra Conditional Access features, and that Microsoft 365 E7 includes those features through Entra Suite. This is an entitlement-documentation clarification; the evidence does not indicate a Conditional Access behavior change.
