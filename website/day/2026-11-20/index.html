Day in brief

Entra sets 2027 SMS and voice MFA retirement dates for users without passkey support

The period’s most consequential change is a Microsoft Entra MFA retirement notice: users who rely solely on Microsoft-provided SMS or voice in sessions that do not support passkeys must register alternative methods or configure customer-managed telephony. Retirement begins February 1, 2027, with July 1, 2027 applying to admins and external users. A separate December rollout will change passkey registration in My Sign-ins. Agent ID guidance also becomes more operationally specific for CIMD and MCP integrations, while Copilot Studio’s Dataverse agent-user capability receives a December 8 general-availability date. Most other updates are routine documentation maintenance.

  • Entra ID · Conditional Access
    SMS and voice MFA retirement now carries two 2027 preparation deadlines

    Microsoft says users relying solely on Microsoft-provided SMS or voice for MFA in sessions that do not support passkeys must register alternative methods or configure customer-managed telephony. Retirement begins February 1, 2027; the notice lists July 1, 2027 for admins and external users. Early preparation is required to avoid sign-in blocks.

  • Entra ID · Authentication
    My Sign-ins passkey registration gets a guided December rollout

    For Microsoft Authenticator users, the My Sign-ins registration experience will add a checkbox, revised link text, and guided steps to start registration. Rollout begins in early December 2026 and completes by the end of December, so organizations should update user communications and internal procedures.

  • Agent ID · General
    CIMD preview guidance specifies endpoint, scope, and token requirements

    The updated Agent ID configuration guidance requires a nonempty MCP endpoint path without a trailing slash, fully qualified delegated scopes, and `organizations` for multitenant authorization servers. It identifies the resource application’s client-ID GUID as the token audience and says not to use client secrets or private-key assertions during preview. Review CIMD and MCP configurations to prevent token acquisition issues.

  • Agent ID · Monitoring
    CIMD consent guidance distinguishes default, strict, and open postures

    The CIMD client documentation now describes default, strict, and open tenant consent postures, including how approval and OAuth scopes behave. It warns that unrestricted consent can enable consent phishing and unauthorized data access; use the strict posture when client onboarding requires administrative review.

  • Agent ID · Provisioning
    Copilot Studio Dataverse agent users receive a December 8 GA date

    Microsoft announced that Copilot Studio will support creating Dataverse agent users with a Microsoft Entra agent’s user account at general availability on December 8, 2026. The announcement provides the availability date but specifies no additional administrator action.
