Day in brief

Microsoft Entra dynamic groups clarify how Agent ID accounts join user groups

14 August was primarily a documentation-clarification day: all 22 entries were updates, with no new or removed items. The meaningful changes explain how agent user accounts are evaluated by dynamic membership rules, sharpen access-package eligibility and assignment wording, and clarify the `{enterprise}` value used in GitHub SCIM setup. A pair of Windows passkey pages dropped “(preview)” from their titles and headings, but the supplied diffs do not announce general availability or a product behavior change. Most remaining Agent ID edits standardize terminology, accessibility text, metadata, or examples.

  • Entra ID · General
    Agent user accounts are now explicitly covered in dynamic-group guidance

    The dynamic membership article explains that agent user accounts are evaluated by user-based membership rules and can join dynamic user groups. By default, the rules do not distinguish them from other users, but administrators can explicitly include or exclude them, including by agent identity blueprint. This is a documentation clarification, not evidence of changed group behavior.

  • ID Governance · Governance
    Access-package guidance removes an inaccurate direct-assignment approval implication

    The Access Package Request Policy article removes wording that implied direct assignment requires approval. It now emphasizes that assigned users must satisfy the applicable policy eligibility requirements; the supplied diff describes a documentation correction rather than a change to assignment behavior.

  • Entra ID · Provisioning
    GitHub SCIM guidance now identifies the enterprise slug for the Tenant URL

    The GitHub Enterprise Managed User Provisioning tutorial explains that `{enterprise}` in the GitHub.com SCIM tenant URL is the enterprise slug, or account name. Administrators configuring provisioning should use that value.

  • Entra ID · Authentication
    Windows passkey article drops “(preview)” without announcing general availability

    The Register a Microsoft Entra passkey on Windows article removes “(preview)” from its title and heading. The supplied diff shows no other change and does not explicitly announce general availability, a launch, or required administrator action.
