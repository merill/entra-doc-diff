Day in brief

Agent registry and collections blades retire May 1; most other changes are documentation maintenance

The most consequential change on 10 April is an Agent ID management transition: Microsoft will retire the Agent registry and Agent collections blades in the Microsoft Entra admin center starting 1 May 2026. Agent 365 becomes the unified agent-management platform, and a new API will replace the existing one. The remaining activity is largely 52 Entra ID documentation updates; the supplied evidence does not establish a new feature launch, general availability change, or tenant-behavior change.
