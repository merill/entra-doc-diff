Day in brief

26 November: Entra guidance sharpened agent governance, token claims, and LDAP SSL setup—no new release evidenced

This was a documentation-led period: 17 pages were updated, none were new, no Message Center items were supplied, and one External ID page was removed. The most substantive updates clarify governed access and ownership for agent identities, the documented OnTokenIssuanceStart flow for custom claims providers, and a certificate-permission prerequisite for on-premises LDAP connector SSL. External ID’s domain-acceleration note and the removal of the Solutions Customers page are documentation changes; the evidence does not establish a product retirement, new availability, or changed service behavior.

  • Entra ID · Standards
    Access packages are documented as the governance model for agent identities

    Updated Entra entitlement-management guidance describes access packages as a way to make agent access intentional, auditable, and time-bound, including standardized access for fleets of agents. This is a governance documentation clarification, not evidence of a new access-package or Agent ID capability becoming available. Organizations governing agent permissions can use the guidance when moving away from ad-hoc assignments.

  • Agent ID · General
    Agent ID guidance calls for maintained sponsors and owners

    The updated guidance says sponsors and owners should be assigned and maintained for each agent ID to prevent orphaned identities. This is lifecycle guidance rather than a stated enforcement change; organizations operating agent IDs should check that ownership is assigned and retained.

  • Entra ID · Authentication
    Custom claims provider documentation clarifies OnTokenIssuanceStart

    The updated overview states that OnTokenIssuanceStart is triggered when a token is about to be issued, is configured within a custom claims provider, and can use a REST API to map claims from external systems into tokens for one or more applications. The change clarifies the documented flow rather than announcing a new event. Administrators using this capability should validate their event, provider, and application assignments against the description.

  • Entra ID · Provisioning
    LDAP connector SSL instructions add a certificate permission prerequisite

    The on-premises LDAP connector preparation guidance specifies that SSL requires granting NETWORK SERVICE read permission on the newly created certificate. This is deployment and security configuration guidance, not a product release. Teams setting up the connector with SSL should include this permission step.

Custom Extension Overview

Updated

The token issuance start event, **OnTokenIssuanceStart** is triggered when a token is about to be issued to an application. It is an event type set up within a [custom claims provider](custom-claims-provider-overview.md). The custom claims provider is a custom authentication extension that calls a REST API to fetch claims from external systems. A custom claims provider maps claims from external systems into tokens and can be assigned to one or many applications in your directory.

Standards

2

Access packages for Agent identities in Microsoft Entra ID

Updated

Microsoft Entra entitlement management provides access packages as a governance mechanism. Access packages ensure that agent access assignments are intentional, auditable, and time-bound. Access packages represent a structured approach to managing agent identity permissions, contrasting with ad-hoc permission assignments that might lack appropriate governance controls. Access packages enable standardized access for many AI Agents with the same access needs, for example, a fleet of customer support AI Agents. Through access packages, organizations can establish consistent governance practices for all agent identity resource access. For more information, see [Governing agent identities](/entra/id-governance/agent-id-governance-overview).
