Day in brief

Microsoft-managed Conditional Access policy nears enforcement for high-risk user remediation

Microsoft is warning that a new Microsoft-managed Conditional Access policy for high-risk users will soon be enforced, while sensitivity labels for Entra cloud security groups are scheduled for mid-November 2026. The period also adds two meaningful ID Governance previews—PIM postapproval extensions and SAP Access Control integration—plus clearer Security Defaults guidance for selected Free tenants.

  • ID Protection · Conditional Access
    Microsoft-managed Conditional Access policy targets high-risk users

    The message says a new Microsoft-managed “Require risk remediation for high-risk users” policy and a new security group were created in the tenant. The policy uses Microsoft Entra ID Protection to identify high-risk users and prompts them to self-remediate through adaptive risk remediation; enforcement is described as soon.

  • Entra ID · Governance
    Sensitivity labels for Entra cloud security groups are scheduled for mid-November

    Microsoft Purview will enable sensitivity labels for Microsoft Entra cloud security groups starting mid-November 2026. Labels can be assigned through multiple platforms, cannot yet be changed once applied, and require tenant configuration separate from Microsoft 365 groups.

  • ID Governance · Governance
    PIM role activation preview adds deferred postapproval checks

    Updated preview guidance adds postapproval extensions with deferred outcomes and asynchronous validation before assignment provisioning. It also documents collecting cost center or project code and requires the relevant Graph permissions and endpoint configuration. The capability requires Entra ID Governance or Entra Suite; Entra ID P2 alone does not include it.

  • ID Governance · Governance
    SAP Access Control preview maps business roles into entitlement management

    New preview guidance describes governing SAP business roles through Microsoft Entra entitlement management catalogs, access packages, and My Access while retaining SAP Access Control workflows and approvals. The documented setup covers SAP BTP, Cloud Connector, prerequisites, licensing, and status reconciliation.

  • Entra ID · Authentication
    Security Defaults guidance enumerates four independently manageable protections

    For selected Microsoft Entra ID Free tenants, the article now describes four separately manageable protections: administrator MFA, user MFA, legacy authentication blocking, and device code flow blocking. It also explains their interaction with Conditional Access and which roles can manage them.

Reminder: Microsoft‑managed CA policy will be enforced soon — Require risk remediation for high‑risk users

New

To strengthen your organization's security posture, Microsoft created a new Microsoft‑managed Conditional Access (CA) policy—Require risk remediation for high‑risk users—in your tenant, along with a new security group for this policy. This policy uses Microsoft Entra ID Protection to identify users at high risk and prompts them to self‑remediate through adaptive risk remediation, allowing users to resolve their own risk without administrator intervention.
