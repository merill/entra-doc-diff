Day in brief

App instance property-lock guidance broadens as External ID documents passkey API setup

Updated Entra ID guidance now describes app instance property locks for both single-tenant and multitenant applications, including the stated default for new applications since June 2026. A new Microsoft Entra External ID credential-management API reference covers signed-in customer passkey listing and registration, while Connect Health installation guidance identifies Global Administrator as the default account with agent-registration permission. Sponsors are also directed from My Access to My Account for guest management. Most remaining edits are narrower documentation corrections.

  • Entra ID · Security
    App instance property-lock guidance covers single-tenant apps

    The configuration article now says locks apply to an application's service principal for both single-tenant and multitenant applications. It also states that `Enable property lock` is enabled by default for new applications since June 2026 and points administrators to `servicePrincipalLockConfiguration`.

  • External ID · Authentication
    External ID documents customer passkey credential-management API

    The new reference explains how signed-in customers can list and register passkeys through the credential-management API, covering delegated authentication, permissions, and setup. Using the API requires manually provisioning its service principal and granting the appropriate delegated permission.

  • Entra ID · General
    Connect Health agent-registration guidance names Global Administrator by default

    The installation page now states that, by default, a Global Administrator account has permission to register the agent, replacing Hybrid Identity Administrator in the documented default.

  • ID Governance · Governance
    Sponsored-guest instructions now point to My Account

    The instructions now direct sponsors to `myaccount.microsoft.com` and the `Sponsored guests` item in the left navigation instead of My Access.
