Day in brief

Hard Deletion Protection preview guidance details seven-day Entra object protection

The period’s main update is new preview guidance for Hard Deletion Protection in Microsoft Entra Backup and Recovery. The documentation also moves an SSPR enforcement date to February 2027, expands documented backup coverage, and adds detailed domainless SAML federation setup guidance for External ID.

  • Entra ID · Security
    Hard Deletion Protection guidance defines a seven-day recovery safeguard

    A new preview article explains how to protect supported Microsoft Entra objects from permanent deletion during the first seven days after soft deletion. It covers prerequisites, supported object types, behavior, audit logging, and setup; configuration is permanent and each operation supports up to 20 objects per type.

  • Entra ID · Authentication
    SSPR directory-property enforcement moves to February 2027

    The SSPR guidance now says the service will stop accepting unregistered directory-sourced properties for verification in February 2027, replacing the October 5, 2026 date. The registration-campaign note was removed, so users should explicitly register authentication methods before enforcement.

  • Entra ID · General
    Backup coverage now includes authentication strengths and OAuth2 grants

    Microsoft Entra Backup and Recovery documentation now includes all authentication strength policy properties and OAuth2 permission grants created through user or administrator consent among recoverable data.

  • External ID · Standards
    External ID adds domainless SAML federation configuration detail

    The guidance adds Microsoft Graph and Graph PowerShell configuration methods and clarifies certificate, endpoint, and domain requirements, including use of a Base64-encoded public certificate and HTTPS endpoints.
