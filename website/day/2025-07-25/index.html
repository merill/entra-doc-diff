Day in brief

25 July: documentation maintenance dominates; iOS QR-code PIN guidance is the notable exception

The period recorded 80 changes, all classified as updates: 76 for Entra ID, 3 for Workload ID, and 1 for Security Copilot. There were no new or removed items and no Message Center entries. The most concrete change is updated Entra ID guidance for iOS QR code PIN authentication, advising MSAL apps how to detect whether an administrator has configured QR code authentication. A broad Conditional Access documentation refresh is the other notable theme. The supplied evidence does not establish a new feature, preview-to-GA transition, retirement, or runtime policy change.

  • Entra ID · Authentication
    Entra ID: iOS QR code PIN authentication guidance clarifies availability detection

    The updated page advises an MSAL app to call `getDeviceInformationWithParameters` to determine whether the administrator has configured QR code authentication. If it is configured, the app can update its UI to show QR code authentication as an available sign-in option. This is an integration/documentation clarification, not evidence of a new Entra ID rollout or changed tenant default.

  • Entra ID · Conditional Access
    Conditional Access reference and operational guidance received a broad refresh

    Multiple Entra ID Conditional Access pages were marked Updated, spanning policy setup, conditions, authentication flows—including the authentication-transfer preview page—sessions, device filtering, report-only mode, resilience defaults, service dependencies, and troubleshooting. Related entries cover Workload ID scenarios involving workload identities. The supplied summaries identify no change to a policy rule, default, availability status, or support boundary, so this should be treated as documentation upkeep,不是?
