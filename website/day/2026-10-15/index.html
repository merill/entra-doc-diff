Day in brief

External ID guidance adds domain_hint routing for invited users

The period centers on new and revised administrator guidance. External ID now has documented invitation-redemption routing through domain_hint, while Entra ID guidance covers Arkose anti-bot verification before telephony-based sign-in. Additional updates clarify Connector Groups routing scope, atypical-travel risk timing, and the causes of a Deactivated application status.

  • External ID · Standards
    Invitation redemption can use domain_hint to select an identity provider

    New External ID guidance explains how the domain_hint authorization parameter routes invited external-tenant users to configured OpenID Connect, SAML/WS-Federation, or social identity providers. It covers invitations through Microsoft Graph or the admin center and custom invitation emails, and lists the external tenant, registered application, associated user flow, configured provider, and domain_hint value as prerequisites.

  • Entra ID · Authentication
    Telephony sign-in guidance adds Arkose verification details

    New Entra ID guidance says users may encounter Arkose Labs anti-bot verification before receiving SMS messages or voice calls. It documents the user experience, network requirements, and help-desk guidance; restrictive firewalls, proxies, or web filtering may require HTTPS access to the specified Arkose Labs domains.

  • Global Secure Access · Authentication
    Connector Groups guidance describes latency-based Performance mode

    The updated Global Secure Access guidance describes Performance mode as routing user traffic to the connector with the lowest measured network latency. It also clarifies that connector load balancing applies only to Microsoft Entra Private Access applications, not application proxy applications, and identifies the routing behavior as preview guidance.

  • ID Protection · Fundamentals
    Atypical travel risk is now documented as real-time

    The ID Protection risk table now lists Atypical travel as “Real-time” instead of “Offline.” Its Premium requirement and unlikelyTravel identifier are unchanged, so administrators reviewing operational expectations should use the updated processing description.

  • Entra ID · Developer
    Deactivated status now requires separate application and sign-in checks

    Updated Entra ID application-property guidance says Deactivated can result from tenant-local sign-in disablement, app registration deactivation, or Microsoft disablement. These conditions can overlap and must be remediated independently, so the status label alone does not identify the underlying cause.
