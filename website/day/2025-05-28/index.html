Day in brief

28 May: External ID’s B2C purchase-status and native-authentication guidance were the clearest changes in an otherwise documentation-maintenance day

All 341 recorded entries were marked Updated; there were no new or removed items and no Message Center notices. The most concrete updates were an External ID statement that Azure AD B2C is no longer available for purchase by new customers as of 1 May 2025, and production guidance for a native-authentication SPA using Azure Front Door as a reverse proxy. Other targeted updates covered Global Secure Access, Conditional Access token protection (Preview), and an Entra permissions reference. The supplied evidence does not support calling these a new feature launch, GA transition, retirement, or runtime behavior change.

  • External ID · Architecture
    External ID: Azure AD B2C purchase availability clarified

    The External ID Secure Fundamentals page was updated to identify Azure AD B2C as the legacy CIAM solution and to state that, effective 1 May 2025, it is no longer available for purchase by new customers. This is a purchase-availability and lifecycle clarification, not an announced shutdown of existing tenants.

  • External ID · Authentication
    External ID native authentication: production Front Door guidance

    The production-environment article was updated for a single-page app that uses the native authentication API and covers Azure Front Door as a reverse proxy. The record supports treating this as implementation guidance, but does not establish a new API release, availability change, or required tenant setting.

  • Global Secure Access · Conditional Access
    Global Secure Access: compliant network check with Conditional Access

    The article on enabling the compliant network check with Conditional Access was updated. The evidence identifies the capability but does not say that it is newly available, that enforcement behavior changed, or that administrators must enable it; this is therefore a documentation update rather than a rollout signal.

  • Entra ID · Conditional Access
    Entra ID Conditional Access token protection remains documented as Preview

    The Entra ID page for Conditional Access token protection was updated and is explicitly labeled “Preview.” No general-availability transition, scope change, or changed token-protection behavior is described in the supplied evidence.

  • Entra ID · General
    Entra ID permissions reference received a specific M365 Backup entry

    The updated Permissions Reference displays the permission `microsoft.backup/restorePoints/userMailboxes/allProperties/allTasks`, described as managing all restore points associated with selected Exchange Online mailboxes in M365 Backup. Because the record only says Updated, it does not establish that the permission was newly introduced or that existing grants need to change.
