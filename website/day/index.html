Day in brief

Microsoft Entra Connect guidance now directs recalled 2.6.79 users to 2.6.91

The period centers on Microsoft Entra Connect version-history and procedure updates. The documentation now identifies Connect 2.6.91.0 as the latest available version, directs users of recalled 2.6.79.0 to uninstall it, and sets 2.6.91.0 or later as the target for upgrades involving an existing ADSync database. Other notable changes document a Connect Sync-to-Cloud Sync migration workflow, passwordless sign-in setup, revised Connect Health navigation, and OAuth2 client-credentials configuration for SCIM endpoints. A new passwordless how-to appeared while the separate Connect Passwordless Authentication page was removed.

  • Entra ID · General
    2.6.91.0 becomes the documented Connect upgrade target

    The version history replaces 2.6.90.0 references with 2.6.91.0 and identifies 2.6.91.0 as the latest available version. It directs administrators upgrading an existing ADSync database to use 2.6.91.0 or later and tells customers using recalled 2.6.79.0 to uninstall it and install 2.6.91.0.

  • Entra ID · Provisioning
    Connect-to-Cloud Sync migration steps are documented for public cloud

    The updated workflow description covers configuration assessment, provisioning agent setup, staged activation, and validation. It remains limited to the Azure public cloud, and rollback is no longer included in the documented workflow.

  • Entra ID · Authentication
    A new how-to details passwordless Connect Sync sign-in

    The new article explains how to enable FIDO2 and passkey methods, register credentials, configure a registry setting, and sign in to Microsoft Entra Connect Sync without a password.

  • Entra ID · Fundamentals
    Connect Health navigation moves monitoring guidance into the Entra admin center

    The installation roadmap now directs administrators to Microsoft Entra Connect Health in the Microsoft Entra admin center for Sync, AD FS, and AD DS settings, troubleshooting, and support. It also states that agents must be installed before monitoring data appears.

  • Entra ID · Standards
    SCIM guidance adds OAuth2 client credentials for non-Entra issuers

    The SCIM endpoint tutorial now documents using an OAuth2 client-credentials grant from a non-Entra issuer, including the token endpoint, client credentials, credential placement, and scopes.
