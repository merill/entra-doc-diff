Day in brief

Microsoft Entra previews request-time Graph policy enforcement with report-only testing and rollback

ID Governance is the clear focus of the period, with a new Microsoft Entra resource policy preview covering request matching, Rego-based custom rules, simulated evaluations, audit diagnostics, report-only assignments, enforcement, and rollback. Licensing guidance says most preview operations require the Entra ID Governance service plan. Separately, Entra ID is preparing risk-based CAPTCHA for SMS and voice MFA from mid-November 2026, while External ID guidance sets TOTP general availability for late November.

  • ID Governance · Governance
    Resource policies can evaluate and enforce matching Microsoft Graph requests

    The new preview guidance covers request matching, Rego applicability and compliance checks, simulated evaluations, enforcement modes, diagnostics, and assignment propagation delays of up to 10 minutes. This establishes request-time governance that can record or block noncompliant configuration changes.

  • ID Governance · Governance
    Report-only deployment and rollback provide a staged enforcement path

    The new deployment guidance recommends testing policies, using report-only assignments to observe real traffic, reviewing evaluation audit events, resolving violations, handling temporary application exceptions, and enabling enforcement only after assessment.

  • ID Governance · Governance
    Most resource policy preview operations require Entra ID Governance licensing

    Updated licensing guidance says most preview resource policy operations require an Entra ID Governance service plan; Entra ID P1 or P2 alone is insufficient. It also specifies that doNotEnforce assignments still evaluate requests, alongside continuing role and API requirements.

  • Entra ID · Authentication
    Risk-based CAPTCHA is coming to SMS and voice MFA

    Microsoft’s Message Center notice says Entra ID will begin adding risk-based CAPTCHA verification from mid-November 2026 to prevent automated fraud. Some users may need to complete CAPTCHA before receiving an SMS code or voice call.

  • External ID · Authentication
    External ID TOTP guidance sets late-November general availability

    Updated External ID MFA guidance now says TOTP authentication in external tenants will become generally available at the end of November 2026, with rollout completing in early December 2026.
