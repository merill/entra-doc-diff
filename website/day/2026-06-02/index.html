2 June 2026: documentation updates sharpen Global Secure Access filtering and SSPR bootstrap guidance; device soft delete is described as a preview

This was a documentation-only day: all 11 recorded changes were Microsoft Learn updates, with no new or removed items and no Message Center entries. The most substantive updates cover existing implementation and operations guidance for Global Secure Access web filtering, SSPR authentication-data synchronization, Private Access, and Entra RBAC. The supplied evidence does not announce a new feature, general-availability milestone, retirement, or service-behavior change.

  • Internet Access · Conditional Access
    Global Secure Access web content filtering guidance

    The updated Microsoft Entra Internet Access how-to describes user-aware internet filtering by website category, URL, and FQDN, using security profiles and Conditional Access. This is an implementation-guidance update; the evidence does not establish that the filtering capability itself launched, changed behavior, or reached general availability.

  • Entra ID · Authentication
    SSPR bootstrap can use synchronized AD DS authentication data

    The updated Entra ID SSPR guidance explains that existing authentication data from Active Directory Domain Services can be synchronized into Microsoft Entra ID and SSPR. Users can then change or reset a password without first registering contact information. The feed presents this as documentation guidance, not a new availability announcement.

  • Entra ID · Fundamentals
    Device soft delete is explicitly scoped as a preview

    The updated Entra ID device-soft-delete page says preview support applies to specified device types. The supplied summary does not name those types or report a scope expansion or general-availability transition, so administrators should verify the current preview scope before relying on the capability.

  • Private Access · General
    Private Access operations guidance is structured around checks and failure handling

    The updated Microsoft Entra Private Access operations page lays out checks with the responsible role, whether the step is automated, the procedure, and what to do if it fails. This is runbook and operational guidance; no Private Access behavior or rollout change is indicated.

  • Entra ID · Fundamentals
    RBAC reference guidance focuses on role assignments and restricted scope

    The updated Entra ID RBAC overview focuses on understanding the components of a role assignment and restricted scope. This is ordinary reference clarification; the supplied evidence does not indicate a change to the permissions model, roles, or assignment behavior.
