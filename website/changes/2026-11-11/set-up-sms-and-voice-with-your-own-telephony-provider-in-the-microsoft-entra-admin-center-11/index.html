Set up SMS and voice with your own telecomtelephony provider in the Microsoft Entra admin center

Before you begin, confirm that your Microsoft Entra policies allow the setup script to create the application and credentials it needs. If you use app management policies for credentials, multitenant apps, or custom Application ID URIs, review them with your Microsoft Entra administrator.

Step 1: Purchase and activate your telecomtelephony provider

  1. Sign in to the Microsoft Entra admin center as an Authentication Policy Administrator.

  2. Go to Entra ID > Authentication methods > Policies and select Add telecom profile. The Set up an SMS or voice provider page guides you through subscription, integration, and profile setup.

    :::image type="content" source="media/choose-your-own-telephony-set-up/setup-overview.png" alt-text="Redacted screenshot of the Set up an SMS or voice provider page and its three setup tasks." lightbox="media/choose-your-own-telephony-set-up/setup-overview.png":::

  3. Select Subscribe to a telecoman SMS or voice provider and choose a supported telecomtelephony provider. Use Get solution to open its offer in Microsoft Security Store, or select an existing subscription with Select details. See Available telephony providers.

    :::image type="content" source="media/choose-your-own-telephony-set-up/subscribe-telecom-provider.png" alt-text="Redacted screenshot of the telecomtelephony provider selection pane. Demo pricing and offer details are obscured." lightbox="media/choose-your-own-telephony-set-up/subscribe-telecom-provider.png":::

  4. Purchase your provider's offer. For detailed purchasing instructions, see Purchase and deploy a SaaS solution from Security Store.

  5. After you Place Order, select Configure Account Now and follow your provider's registration instructions.

Step 2: Deploy the integration

On Set up an SMS or voice provider, select Set up the provider integration. Select the Azure hosting subscription and review the telecomtelephony provider configuration populated in the pane.

:::image type="content" source="media/choose-your-own-telephony-set-up/integration-setup.png" alt-text="Redacted screenshot of the provider integration pane with subscription selection, Function App setup, registration guidance, and Verify." lightbox="media/choose-your-own-telephony-set-up/integration-setup.png":::

What the setup script does

The setup script deploys everything needed to connect Microsoft Entra ID to your telecomtelephony provider, so you don't have to create Azure resources by hand. It walks you through a few choices, then shows the full deployment plan. Nothing is created until you approve it.

After you approve, the script creates the Microsoft Entra application, deploys and secures the Azure resources, and applies your provider's configuration. Deployment usually takes a few minutes.

Costs

!Important

The integration runs on Azure resources in your subscription, billed based on your configuration and usage. To plan your budget, see Estimate telephony-provider and Azure hosting costs before you deploy.
