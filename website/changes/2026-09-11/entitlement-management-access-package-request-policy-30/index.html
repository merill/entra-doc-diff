Entitlement Management Access Package Request Policy

11 September 2026Doc update+1 / −1 lines

In brief

The documentation now specifies that existing guest users can be directly assigned, but external users who are not yet in the directory cannot be invited through direct assignment when access is limited to administrator direct assignments.

What Entra admins need to know

Review this guidance when assigning external users under the “None (administrator direct assignments only)” policy.
