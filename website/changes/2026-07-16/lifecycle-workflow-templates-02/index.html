Transition agent sponsorships when a sponsor leaves

The Transition agent sponsorships when a sponsor leaves template is designed to configure tasks that transition agent sponsorships when a sponsor leaves the organization. This template is available for tenants with the Microsoft Agent 365 license. For more information, see: Microsoft Agent 365 Documentation.
