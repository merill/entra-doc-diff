Run a Registration Campaign to Set Up a Passkey or Microsoft Authenticator

15 September 2026Feature update+9 / −7 lines

In brief

The documentation now distinguishes Microsoft-managed and enabled campaigns. It specifies the MFA method required for each targeted authentication method and broadens eligible users from SMS or voice sign-ins to users signing in with any MFA method.

What Entra admins need to know

Administrators should use the campaign-state-specific requirements when configuring or troubleshooting MFA registration campaigns.
