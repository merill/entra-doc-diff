Tenant Restrictions V2

24 November 2026Doc updateAction required+1 / −1 lines

In brief

The documentation replaces specific TLS inspection and header-injection exclusions with guidance to test proxy configurations and confirm tenant restrictions v2 and client-certificate authentication flows work.

What Entra admins need to know

Administrators should test affected proxy configurations, particularly for device and certificate-based authentication.

!Important

Tenant restrictions v1 and v2 on the proxy require decryption of requests to sign-in URLs such as login.microsoftonline.com. Microsoft supports the decryption of traffic for those sign-in domains for the purpose of header insertion for tenant restrictions. This decryption is a valid exception to the policies at Use third-party network devices or solutions with Microsoft 365.

Exclude device.login.microsoftonline.com, certauth.login.microsoftonline.com, and *.certauth.login.microsoftonline.com from TLS inspection and header injection. These exclusions preserve device authenticationinjection can interfere with authentication flows that use client certificates.
