[!INCLUDE entra-id-license-pim.md]

PIM for app roles (preview) requires Microsoft Entra ID Governance licenses. Microsoft Entra ID P2 alone isn't sufficient.

License coverage is required for users with eligible or time-bound app role assignments and for request approvers.

What does it do?

Privileged Identity Management provides time-based and approval-based role activation to mitigate the risks of excessive, unnecessary, or misused access permissions on resources that you care about. Here are some of the key features of Privileged Identity Management:

  • Download audit history for internal or external audit
  • Prevent removal of the last active Global Administrator and Privileged Role Administrator role assignments

The available capabilities depend on the PIM provider. For the app roles preview's workflows, see PIM for app roles (preview).

Privileged access capabilities in preview

PIM also includes preview capabilities for role activation, agent access, and privileged sessions. Licensing and setup requirements vary by feature; see the linked guides for prerequisites.

  • Activate roles in My Access. Activate eligible Microsoft Entra roles, Azure resource roles, and group membership or ownership from one portal. See Role activation in My Access (preview).
  • Govern Azure resource access for agents.agents and agent identities. Assign eligible Azure resource roles to agents and agent identities so they can activate access only when needed. See Eligible assignments for agents (preview) and Agent identity activation (preview)PIM assignment support.
  • Connect to virtual machines. Use My Access to activate existing eligible access for Azure virtual machines or supported Azure Arc-enabled Linux servers. Then connect through an available path, including Azure Bastion. See Virtual machine connections in My Access (preview).
  • Review session activity and recordings. Session analytics show PIM role lifecycle and Azure Bastion connection activity, not commands run inside a virtual machine. With Azure Bastion Premium and recording configured, you can review recordings of supported connections. See Session analytics (preview) and Azure Bastion session recordings (preview).
  • Manage active sessions. Find and disconnect selected active Azure Bastion sessions without deactivating the user's role assignments. See Session management in PIM (preview).
