Quickstart: Assign and test a built-in Microsoft Entra resource policy (preview)

19 November 2026Doc update+9 / −6 lines

In brief

The quickstart now explains that other assignments can affect simulated requests and that the documented response fields apply only when no other assignment changes the result. It also clarifies how to distinguish report-only violations using `details[].appliedPolicyEffects`.

What Entra admins need to know

Administrators should consider all applicable assignments when interpreting `200 OK` and `isBlocked: false` responses.
