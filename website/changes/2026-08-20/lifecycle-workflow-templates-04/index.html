Lifecycle Workflow Templates

20 August 2026Doc update+3 / −3 lines

In brief

The mover workflow templates now list the “Remove all access package assignments for user” task, with removal scheduled by default for 15 days.

What Entra admins need to know

Administrators reviewing mover workflows can account for scheduled removal of all access package assignments.
