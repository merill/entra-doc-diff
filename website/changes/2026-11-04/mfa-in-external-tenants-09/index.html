MFA in external tenants

4 November 2026New feature+16 / −7 lines

In brief

The documentation now describes time-based one-time passwords (TOTP) as an MFA method, including registration by QR code and verification codes from Microsoft Authenticator or supported third-party apps.

What Entra admins need to know

Administrators can configure TOTP as a second-factor method alongside SMS or other supported options.

Multifactor authentication in external tenants

  • Email one-time passcode
  • SMS-based authentication, available as an add-on (see details).
  • Time-based one-time password (TOTP) from Microsoft Authenticator or a supported third-party authenticator app (see details).
  • Passkey (FIDO2). Passkeys are a phishing-resistant authentication method that can satisfy MFA in a single gesture and also enable passwordless sign-in (see details).

Enforcing MFA enhances your organization's security by adding an extra layer of verification, making it more difficult for unauthorized users to gain access.

Depending on which option you choose as the first factor, different second-factor verification methods are available for multifactor authentication (MFA).

  • Email with password or username with password: For these first-factor methods, you can enable email one-time passcode, SMS, TOTP, passkey (FIDO2), or a combination as second-factor verification methods for MFA.
  • External identity providers: You can enable email one-time passcode, SMS, TOTP, or a combination as second-factor verification methods for MFA. Passkey (FIDO2) isn't currently available for users who sign in with an external identity provider.
  • Email one-time passcode: When email with one-time passcode is selected as the first-factor authentication method, it can't be used for second-factor verification. Email one-time passcode

Starting January 2025, certain country codes will be deactivated by default for SMS verification. If you want to allow traffic from deactivated regions, you need to activate them for your application using the Microsoft Graph onPhoneMethodLoadStartevent policy. See Regions requiring opt-in for SMS verification.

Time-based one-time password (TOTP)

TOTP is a standards-based method that generates a temporary verification code in Microsoft Authenticator or a supported third-party authenticator app. It works as a second-factor verification method for MFA in external tenants.

When TOTP is enabled and MFA is required, users register an authenticator app by scanning a QR code. For subsequent MFA challenges, users enter the verification code displayed in their authenticator app.

For setup steps, see Add multifactor authentication (MFA) to an app.

Passkey (FIDO2)

Passkeys (FIDO2) provide phishing-resistant, passwordless authentication that uses public-key cryptography. A passkey can be used to satisfy MFA in a single gesture (face, fingerprint, PIN, or security key) or as a primary, passwordless sign-in method. Only email + password and username + password local account users can register a passkey. Passkey registration requires a custom URL domain, and users must complete MFA before registering a passkey.
