What is cross-tenant synchronization in Microsoft Entra ID?

4 November 2026Feature update+13 / −3 lines

In brief

The documentation explains how to synchronize a group’s role-assignability using a direct `isAssignableToRole` mapping during target-group creation. Role assignments remain separate, and existing non-role-assignable groups aren’t converted.

What Entra admins need to know

To use this capability, enable the relevant inbound synchronization settings and configure the source mapping. Assign roles separately in each target tenant.

Can I synchronize role-assignable groups?

Yes, when role-enabled group sync is available in your environment. Enable inbound group synchronization and inbound role-enabled group synchronization in the target tenant, and configure a direct isAssignableToRole attribute mapping in the source tenant. Apply the mapping only during object creation, before adding role-assignable groups to the synchronization scope.

Role-enabled group sync synchronizes the group's ability to receive role assignments. It doesn't copy role assignments from the source tenant. Assign the required roles separately in each target tenant.

The isAssignableToRole property is set when the target group is created and can't be changed afterward. Adding the mapping doesn't convert previously synchronized non-role-assignable target groups. For configuration and replacement guidance, see Configure role-enabled group sync.
