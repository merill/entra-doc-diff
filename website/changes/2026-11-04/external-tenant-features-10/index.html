External Tenant Features

4 November 2026Doc update+4 / −2 lines

In brief

The supported-features table now lists time-based one-time password (TOTP) as an MFA authentication method for customers.

What Entra admins need to know

Administrators can consider TOTP when evaluating MFA options; no action is required.
