In brief

The documentation now states that application management policies aren't available in external tenants and recommends expiration settings for client secrets. Fraud-protection integrations are described for Microsoft-hosted sign-up flows, with the native API tutorial reference removed.

What Entra admins need to know

This clarifies which credential controls and sign-up flows apply when planning an external tenant deployment.

Continuous system validation

Changes in environments are inevitable. An automated continuous validation environment helps catch issues caused by changes. You can use the same syntacticsynthetic monitoring infrastructure to set up this validation automation.

Synthetic transactions can reference applications and APIs used for token acquisition, validation, and integration components such as API managers and service buses. We recommend you maintain versions of supported services, operating systems, and runtime environments. Each component continuously reports test success or failure. This action ensures identity services availability and early detection of potential failures.
