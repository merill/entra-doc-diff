Enable and support passkeys in Authenticator for Microsoft Entra ID

17 November 2026Feature updateAction required+20 / −7 lines

In brief

The documentation now requires administrators to opt users into the dedicated registration resource through Microsoft Graph, then exclude it from applicable Conditional Access policies. Android users also need Microsoft Authenticator 6.2607.4697 or later.

What Entra admins need to know

Provision the enterprise application, configure the opt-in as a Conditional Access Administrator, and update applicable policies before passkey registration becomes available at the end of November 2026.
