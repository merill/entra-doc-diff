Microsoft Entra Backup and Recovery overview

Microsoft Entra Backup and Recovery is a built-in backup and recovery solution that lets you recover critical Microsoft Entra directory objects to a previously known good state after accidental changes or security compromises. This overview explains how daily backups work, the differences between the Standard and Premium plans, and the prerequisites for each plan.

Supported objects include users, groups, apps, service principals, Conditional Access policies, named locations, authentication method policy, authentication strength policies, and authorization policy (selected properties). The solution also supports Agent ID because it consistsagent identities, which consist of userusers, apps, and service principal objectsprincipals with distinct types and characteristics.

How backups work

Microsoft Entra Backup and RecoveryThe Standard plan takes backups of supported objects automatically, once a day, retainingand retains up to seven days of backup history. The Standard plan is included with Microsoft Entra ID P1 and P2 licenses. The solution helps restore your tenant to a productive and secure state. Microsoft regularly improves and expands the solution to support more directory objects and more attributes.

Microsoft creates Standard plan backups automatically and makes them available to administrators with sufficient permissions. No signed-in user or application, even with the highest admin privileges, can turn off, delete, or modify Standard plan backups in the tenant. Backup data resides securely in the same geo-location as the Microsoft Entra tenant, determined during tenant creation.

Standard and Premium plans

  • Standard: Included with Microsoft Entra ID P1 and P2 licenses and retains up to 7 days of backup history.
  • Premium (preview): An optional, consumption-based plan that retains up to 30 days of backup history. It offers faster initial difference report generation and recovery by skipping the one-time data loading phase for each backup.

Premium charges depend on the number of protected directory objects captured in each backup. Configure billing and turn on Premium in the Microsoft 365 admin center. Microsoft Entra Backup Administrator is the least-privileged role that can turn on Premium for your tenant. For setup instructions, see Set up Microsoft 365 Backup.

For plan features and what happens when you turn Premium on or off, see Microsoft Entra Backup and Recovery plans.

  • Settings: View the current plan.
  • Hard deletion protection (preview): Enable permanent protection for supported objects and view protected-object counts.

To turn on the Premium plan, see Set up Microsoft 365 Backup.

Prerequisites

To use Microsoft Entra Backup and Recovery, your tenant must meet these requirements:

  • The tenant is a workforce tenant. External ID and Azure AD B2C tenants aren't supported.
  • TheTo use the Standard plan, the tenant has Microsoft Entra ID P1 or P2 licenses.
  • To use the Premium plan, the tenant has at least one SharePoint license or a license that includes SharePoint. Microsoft Entra ID P1 or P2 licenses aren't required.
  • You're signed in with one of these roles:
    • Microsoft Entra Backup Reader: Can view backups, view comparisons of changed objects between the backup state and the current state, and review recovery history.
