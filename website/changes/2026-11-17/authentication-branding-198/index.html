Authentication Branding

17 November 2026Public preview+21 / −15 lines

In brief

The article now covers Microsoft-hosted sign-in, sign-up, and sign-out pages, with updated branding and language guidance. It also documents Fluent, Basic, Advanced, and custom HTML customization options scheduled for preview on December 7, 2026, for enabled external tenants.

What Entra admins need to know

Administrators can review the new application branding theme options. Existing company-branding procedures continue to apply to default branding; no immediate action is required.
