Microsoft Entra External ID Overview

17 November 2026Doc update+7 / −4 lines

In brief

The overview now lists Microsoft-hosted authentication, Embedded native authentication, and BYO UX for customer-app authentication. It also specifies that company branding customizes Microsoft-hosted sign-in pages.

What Entra admins need to know

Administrators can use the updated guidance to understand which authentication experience the branding settings apply to.
