How are agent identities created?

17 November 2026Feature updateAction required+9 / −8 lines

In brief

The documentation now states that agent identity blueprint principals cannot create agent identities or agent user accounts until an administrator grants the corresponding permissions. It also corrects the delegated permission name to `AgentIdentity.ReadWrite.All`.

What Entra admins need to know

Administrators must grant the required permissions before blueprint principals can create identities or user accounts.
