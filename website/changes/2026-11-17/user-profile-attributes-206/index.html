User profile attributes

[!INCLUDE applies-to-external-only]

The user attributes you collect during sign-up are stored with the user's profile in your directory. You can choose from built-in user attributes or create custom user attributes.

Use the Find the application ID for the extensions app article to learn how to find the application ID for the b2c-extensions-app registered in your external tenant.

Attribute collection in your interface

For Embedded native authentication and BYO UX, follow the native authentication attribute contract. Use exact returned attributeId values, current requirements, and validation metadata rather than copying the directory property table into a request. Native Authentication API submissions use string values even when the directory attribute has a Boolean or integer data type.

For an existing V1 SDK integration, use the MSAL Android library for library-specific attribute types. Those types aren't the response schema for the Native Authentication API.

Microsoft Graph APIs

User attributes are referred to as user flow attributes in Microsoft Graph. Use the identityUserFlowAttribute resource type and its associated methods to manage both built-in and custom user flow attributes.

These management APIs have their own permission and resource-token requirements. Signing in through the Native Authentication API doesn't grant directory-management access.
