Supported features in Microsoft Entra External ID workforce and external tenants

There are two ways to configure a Microsoft Entra tenant,External ID supports two tenant configurations, depending on how an organization intends to use the tenantyour audience and the resources that you want to manage:

  • A workforce tenant configuration is for your employees, internal business apps, and other organizational resources. A workforce tenant uses B2Bbusiness-to-business (B2B) collaboration in Microsoft Entra External ID for collaborationto work with external business partners and guests.
  • An external tenant configuration is exclusively for External ID scenarios where you want to publish apps to consumers or business customers.
