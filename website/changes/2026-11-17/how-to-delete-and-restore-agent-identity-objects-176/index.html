How to delete and restore agent identity objects

17 November 2026Doc update+55 / −28 lines

In brief

The documentation no longer states that deleting a blueprint automatically soft-deletes child agent identities and agent user accounts. It now treats blueprint applications and principals as separate delete targets, and lists separate permissions for deletion, restoration, and permanent deletion.

What Entra admins need to know

Do not assume deletion or restoration cascades to related objects. Record related object IDs and verify them independently, and review the listed permissions for your operations.

Delete an agent identity

Use the agentIdentity-specific Graph operation to delete one agent identity. The API moves the object to a temporary container, where it can be restored within 30 days.

DELETE https://graph.microsoft.com/beta/servicePrincipals/{agent-identity-object-id}/microsoft.graph.agentIdentity

For the API's permissions and current behavior, see Delete agentIdentity.

Restore a blueprint principal

You can restore a soft-deleted blueprint principal within 30 days. Restoring an application doesn't automatically restore its associated service principal, so restore the blueprint principal separately. Restoring agent identity objects isn't supported in the Microsoft Entra admin center. Use Microsoft Graph API or Microsoft Entra PowerShell. For details, see Restore deleted items.
