Migrate from Microsoft Entra Connect Sync to Cloud Sync: Decision Guidedecision guide

Microsoft Entra Cloud Sync represents Microsoft's strategic direction for hybrid identity synchronization. It provides cloud-managed synchronization of users, groups, and contacts between Active Directory and Microsoft Entra ID. When device sync is enabled, Cloud Sync can synchronize Active Directory computer objects to Microsoft Entra ID for hybrid join.

This decision guide helps IT architects and decision makers evaluate migration from Microsoft Entra Connect Sync to Cloud Sync by comparing technical capabilities, identifying architectural advantages, and providing migration readiness assessments. For basic overview information, see What is Microsoft Entra Cloud Sync?. For step-by-step migration procedures, see Migrating from Microsoft Entra Connect to Microsoft Entra Cloud Sync.

New identity and synchronization features are being developed primarily on the Cloud Sync platform, making it the recommended path forward for most organizations.

The following table provides a detailed comparison of technical capabilities between Microsoft Entra Connect and Cloud Sync:

!Note

This table describes capabilities available in Connect Sync and Cloud Sync. It doesn't indicate whether the guided migration tool can transfer each capability. Review the guided migration-tool prerequisites and limits before starting migration.

Feature/Capability Connect Sync Cloud Sync Technical Notes
Users, Groups, Contacts Sync ✓ ✓ Full parity for basic directory object synchronization
Single Connected Forest ✓ ✓ Both support standard single-forest topologies
Multiple Connected Forests ✓ ✓ Both support multiple connected forest scenarios
Disconnected Forest Support ✗ ✓ Cloud Sync enables M&A scenarios without forest consolidation
Device Synchronization ✓ ✓ Both support device synchronization for Microsoft Entra hybrid join; enable device sync separately in Cloud SyncSync. The current guided migration tool lists device synchronization as a migration blocker. Review the migration-tool requirements separately.
Multiple Active Sync Instances ✗ ✓ Cloud Sync agents provide automatic failover and load distribution
Scale Limits per Domain Unlimited 150K objects Cloud Sync currently supports up to 150,000 objects per domain
Large Group Support 250K members 50K members Connect supports larger groups; Cloud Sync limited to 50,000 members

Ready for immediate migration

Your organization can migrate immediately if you meet allUse these criteria:criteria to assess platform readiness. They don't establish guided-tool eligibility or replace a documented migration procedure:

  • Object Scale: Fewer than 150,000 objects per Active Directory domain
  • Group Size: Groups with fewer than 50,000 members
  • Plan Migration Timing: Monitor feature announcements, consider business cycles, and assess resource availability
  • Validate Prerequisites: Ensure your environment meets Cloud Sync prerequisites
  • Test Migration Process: Use the pilot migration tutorial to validate the migration process

Choose an outcome based on both platform support and the available migration path:

  • Use the guided migration tool: Your organization and active Connect Sync installation meet the current tool requirements, and the readiness review confirms eligibility.
  • Use documented manual guidance: Cloud Sync supports your required scenario and Microsoft provides a documented manual migration procedure. Review the migration overview and manual pilot tutorial.
  • Continue using Connect Sync: A required capability or documented migration path isn't available. Review the feature comparison. If a confirmed blocker prevents you from meeting a notified migration deadline, request more time.
