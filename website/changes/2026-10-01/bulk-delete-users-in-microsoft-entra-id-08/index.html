Bulk delete users in Microsoft Entra ID

Overview

Using the admin center in Microsoft Entra ID, part of Microsoft Entra, you can remove a large number of users by using a comma-separated values (CSV) file to bulk delete users.

Prerequisites

To bulk delete users in the Microsoft Entra admin center, sign in as at least a User Administrator.

Bulk delete users

!Important

Updates are being made to bulk operations. While this issue is being addressed, you might experience problems deleting users assigned to privileged roles. This problem is temporary and is being resolved as soon as possible.

  1. Sign in to the Microsoft Entra admin center

    1. Sign in to the Microsoft Entra admin center as at least a User Administrator.

    2. Select Microsoft Entra ID. :::image type="content" source="./media/users-bulk-delete/users-bulk-delete.png" alt-text="Screenshot of the Users page with the Bulk delete option selected.":::

    3. On the Bulk delete user page, select Download to download the latest version of the CSV template.

    4. Open the CSV filefile, preserve the column header exactly as downloaded, and add a line for each user you want to delete. The only required value isFor each user, enter either the User principal name or Object ID. Save the file.

    5. On the Bulk delete user page, under Upload your csv file, browse to the file. When you select the file and select Submit, validation of the CSV file starts.

    6. When the file contents are validated, you’ll see File uploaded successfully. If there are errors, you must fix them before you can submit the job.

    7. When your file passes validation, select Submit to start the bulk operation that deletes the users.
