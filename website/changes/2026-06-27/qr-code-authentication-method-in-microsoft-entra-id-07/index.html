Enforce QR code sign-in with a custom authentication strength

To require QR code sign-in for a specific resource, create a custom Conditional Access authentication strength that includes QR code under Single factor authentication. Then use the custom authentication strength in a Conditional Access policy for the resources and users that need QR code sign-in. For steps, see Create and manage custom Conditional Access authentication strengths.

To require QR code sign-in for a specific group of users, such as frontline workers, a specific resource, or both, create a custom Conditional Access authentication strength that includes QR code under Single factor authentication. Then use the custom authentication strength in a Conditional Access policy for the resources and users that need QR code sign-in. For steps, see Create and manage custom Conditional Access authentication strengths.
