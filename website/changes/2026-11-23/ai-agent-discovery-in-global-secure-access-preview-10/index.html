How AI agent discovery works

Users run local AI agents and tools, such as command-line assistants, desktop clients, and integrated development environment (IDE) extensions. These agents connect to model providers, MCP servers, and other internet destinations. When this traffic flows through Global Secure AccessAccess, the service inspects internet-bound network trafficit to identify AI agent activity. Because Global Secure Access already sits inline in the network path, so discovery doesn't require new agents, sensors, or endpoint changes.

      AI agent discovery insights are available in the Global Secure Access experience in the Microsoft Entra admin center.

      1. Sign in to the Microsoft Entra admin center as at least a Global Secure Access Log ReaderGlobal Secure Access Log Reader.

      3. Select the widget, or browse to Global Secure Access > Overview dashboard.

      The AI agent discovery page shows local and cloud agent activity in one inventory. It opens with a summary of your environment:

      • Total agents: All AI agents discovered on the network.
      • Managed: Agents that are governed through Microsoft Agent Discovery365.
      • Unmanaged,: Discovered agents that aren't governed yet, including shadow agents.

      Each row in the inventory represents an agent type, such as OpenClaw, GitHub Copilot CLI, or a Copilot Studio agent. The inventory has the following columns:

      ColumnDescription
      AgentThe identified agent type, for example, OpenClaw, GitHub Copilot CLI, Cursor, or Ollama Desktop.
      Agent type IDThe unique identifier of the agent type.
      PlatformWhere the agent runs. clientPlatform indicates a local agent on an endpoint. aiAgentPlatform indicates a cloud agent, such as a Copilot Studio agent.
      Is managedWhether the agent is governed through Microsoft Agent 365.
      TransactionsThe number of network transactions attributed to the agent type. Select the value to open the traffic logs filtered to this agent type.
      AgentsThe number of individual agents of this type that have an agent ID, such as Copilot Studio agents. Select the value to open the Agents tab of the details pane.
      UsersThe number of distinct users who ran the agent. Select the value to open the Users tab of the details pane.
      DevicesThe number of distinct devices that the agent ran on. Select the value to open the Devices tab of the details pane.
      DestinationsThe number of unique destinations that the agent connected to. Select the value to open the Destinations tab of the details pane.
      Sent bytesThe volume of data that the agent sent.
      Received bytesThe volume of data that the agent received.
      Last accessWhen the agent was most recently seen on the network.
      First accessWhen the agent was first seen on the network.
