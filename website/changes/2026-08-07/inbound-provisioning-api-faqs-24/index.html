In brief

The FAQ changes “Scoping filter” to “scoping filter” and clarifies that administrators define scoping filter rules to include or exclude users from processing. The existing Sales example remains.

What Entra admins need to know

No product or configuration change is indicated; administrators may simply use the updated terminology when consulting the FAQ.
