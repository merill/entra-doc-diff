Samples and guides for integrating apps with External ID

6 October 2026Doc update+11 / −6 lines

In brief

The page now links to a sample for listing and registering passkeys and documents delegated permissions for those operations. It also warns that deletion uses high-privilege application permissions and a client secret in browser code.

What Entra admins need to know

No general action is required. Run the sample only in a test tenant, never in production.
