Configure Snowflake SSO

  1. In a different web browser window, sign in to Snowflake as a Securityan Account Administrator.

  2. Switch Role to ACCOUNTADMIN, by selecting profile on the top right side of page.

  3. Create a SQL notebook, paste the following, but do not run it.

    CREATE [ OR REPLACE ] SECURITY INTEGRATION [ IF NOT EXISTS ]
<name>
TYPE = SAML2
ENABLED = TRUE | FALSE
SAML2_ISSUER = '<EntityID/Issuer value which you have copied>'
[ SAML2_SNOWFLAKE_ACS_URL = '<string_literal>' ]

  4. Set the name of the SAML integration.

  5. Open the downloaded Base 64 certificate in notepad.a text editor such as Notepad. Copy the value between “-----BEGIN CERTIFICATE-----” and “-----END CERTIFICATE-----" and paste this content into the SAML2_X509_CERT.

  6. In the SAML2_ISSUER, paste Identifier value, which you copied previously.

  7. In the SAML2_SSO_URL, paste Login URL value, which you copied previously.

  8. In the SAML2_PROVIDER, give the value like CUSTOM.

  9. Select the All Queries and select Run.
