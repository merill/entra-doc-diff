Native Authentication Configure App

18 November 2026Feature updateAction required+7 / −5 lines

In brief

Browser-based apps, including SPAs, require a tenant-verified custom domain for Native Authentication API V2. Android and iOS apps using native HTTP transports can use their configured service authority without a custom domain.

What Entra admins need to know

Ensure a verified custom domain is configured for browser-based integrations; native mobile clients do not require one.
