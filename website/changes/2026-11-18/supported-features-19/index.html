Authority URL in OpenID Connect and OAuth2 flows

The authority URL indicates a directory that the Microsoft Authentication Library (MSAL) can request tokens from. For Microsoft-hosted authentication in external tenants, use the default <tenant-name>.ciamlogin.com domain or a tenant-verified custom URL domain.

For currentbrowser-based apps using the Native Authentication API V2 and Bring Your Own UX (BYO UX) service API calls,, use a tenant-verified custom domain. Include and include the tenant GUID in the URL path. This browser requirement helps protect against cross-site request forgery (CSRF). Non-browser clients, such as iOS and Android apps using native HTTP transports, don't require a custom domain. See Configure the API authority.
