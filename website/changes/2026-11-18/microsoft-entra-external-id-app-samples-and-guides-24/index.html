Microsoft Entra External ID app samples and guides

18 November 2026Feature update+8 / −8 lines

In brief

The CIAM samples documentation now lists minimum versions for MSAL JavaScript (5.29.1), Android (8.7.0), and Apple (2.18.1), and updates sample and release links.

What Entra admins need to know

Review these documented SDK requirements when supporting native authentication applications and direct development teams to the updated samples.
