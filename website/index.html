Day in brief

Agent blueprint shutdowns can disrupt other tenants as provisioning diagnostics expand

The period adds a new troubleshooting resource for HR-driven provisioning timeouts and sharpens operational guidance for Agent ID, Cloud Sync, and Global Secure Access. The most consequential change is the explicit warning that disabling a multi-tenant agent blueprint can impair related agents in other tenants.

  • Agent ID · General
    Global Agent ID disablement now documents cross-tenant disruption risk

    The procedure for multi-tenant blueprints now uses **Disable** > **Disable in all tenants**. The guidance says related agents in other tenants can fail or lose functionality, so administrators should assess that impact before proceeding.

  • Entra ID · Troubleshooting
    New HR provisioning timeout guidance traces delays across the integration chain

    A new troubleshooting article covers intermittent timeouts and slow provisioning from Workday, SAP SuccessFactors, and API-driven HR integrations to on-premises Active Directory. Its checklist addresses job status, provisioning agents, matching attributes, domain controllers, DNS, connectivity, logs, and required roles.

  • Entra ID · General
    Cloud Sync prerequisites now call out DNS and Active Directory site mapping failures

    The prerequisites explain that incorrect DNS, subnet-to-site mappings, or site configuration can cause synchronization failures, performance problems, and intermittent connectivity. They direct administrators to correctly map provisioning-agent server subnets in Active Directory Sites and Services.

  • Global Secure Access · General
    Global Secure Access moves Explicit Forward Proxy settings under Connect

    The documented path is now Global Secure Access > Connect > Explicit Forward Proxy, replacing the previous Session management location for accessing the configuration.
