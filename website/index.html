Day in brief

Cloud Sync group provisioning gets a dedicated tutorial as combined guidance is removed

Microsoft’s 31 August Entra changes reorganized Cloud Sync guidance around group provisioning. A new AD DS tutorial covers Entra-to-AD and AD-to-Entra scenarios, while the main configuration article was rewritten for groups with new scoping, attribute-mapping, testing, and default-setting sections. Seven older pages were removed, including guidance on prerequisites, deployment options, provisioning behavior, and test-and-enable procedures.

  • Entra ID · Provisioning
    A dedicated Cloud Sync tutorial now covers group provisioning to AD DS

    The new tutorial explains how to configure Microsoft Entra Cloud Sync to provision groups to on-premises AD DS. It covers both Entra-to-AD and AD-to-Entra scenarios, including how source of authority and membership affect provisioning, and recommends Selected security groups as the default scoping filter to help prevent performance issues.

  • Entra ID · Provisioning
    The group provisioning configuration guide replaces combined users-and-groups instructions

    The rewritten guide adds setup steps, screenshots, scoping, attribute mapping, testing, and default settings for provisioning groups from Microsoft Entra ID to Active Directory. It removes the previous combined users-and-groups guidance and adds a deprecation notice.

  • Entra ID · Provisioning
    Topology guidance adds explicit membership and identifier requirements

    Plan Cloud Sync Topologies now states that cloud-synced groups can contain only on-premises synchronized users and additional cloud-created security groups, and that all users must have `onPremisesObjectIdentifier`. The example link and diagram descriptions were also updated.

  • Entra ID · Provisioning
    On-demand group tests now select up to five members

    The updated on-demand provisioning instructions tell administrators to select a group and manually choose up to five members for testing. User-specific instructions and result-review details were removed, and references now target provisioning from Microsoft Entra ID to Active Directory.

  • Entra ID · Provisioning
    The Cloud Sync test-and-enable page was removed

    The deleted page covered on-demand tests, default properties, enabling configurations, quarantines, restarting sync, and removing configurations. Administrators can no longer use it as the documented reference for validating and managing Cloud Sync provisioning configurations.
