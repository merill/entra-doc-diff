Week in brief

Microsoft Entra rolls out a People administrator role while ID Protection alerts move to Defender XDR

The supplied record for the week of 3 March contains two Microsoft 365 Message Center notices and no documentation additions, updates, or removals. Microsoft Entra is rolling out a new People administrator role, while Entra ID Protection alerts are being removed from Microsoft Defender for Cloud Apps and integrated into Microsoft Defender XDR.

  • Entra ID · Security
    New People administrator role begins rollout

    Microsoft Entra is introducing a People administrator role based on customer feedback. It allows management of people-related settings and profile photos without requiring high privileges. The stated rollout began in early February 2025 and is expected to complete by late March; the notice describes a rollout but does not establish preview or general-availability status.

  • ID Protection · Monitoring
    ID Protection alerts leave Defender for Cloud Apps

    Starting 5 March 2025, Microsoft Entra ID Protection alerts are no longer available in Microsoft Defender for Cloud Apps and are integrated into Microsoft Defender XDR. This is a change to where the alerts are surfaced, not an evidence-based statement that ID Protection alerting itself is being retired. The notice says no admin action is required, while recommending configuration review and user notification.

For Entra administrators

The People administrator role is intended to support people-related administration and profile-photo management without requiring high privileges; the notice does not specify assignment steps or label the capability as preview or generally available. For ID Protection, the notice says no administrator action is required, but asks administrators to review their configuration and notify users about the change in alert location.
