Week in brief

SPO OTP retirement and Connect hardening reshape Entra administration this week

Microsoft is retiring SharePoint One-Time Passcode authentication starting in mid-October 2026, moving external sharing to Microsoft Entra B2B and guest accounts. Updated Connect Sync guidance ties synchronization continuity to a minimum version and application-based authentication by April 7, 2027, while Entra sign-in will block external script injection from mid-October. Other notable developments include public-preview App Gallery onboarding and more explicit Conditional Access targeting guidance for agent users; most remaining updates were documentation maintenance.

  • External ID · Conditional Access
    SharePoint OTP retirement moves external sharing to Entra B2B

    SPO OTP authentication will begin retiring in mid-October 2026 across Microsoft 365 tenants. External users will require Microsoft Entra B2B guest accounts, bringing SharePoint and OneDrive sharing under consistent governance and Conditional Access.

  • Entra ID · Security
    Connect Sync guidance sets 2.6.84.0 and app-auth deadline

    Updated security guidance raises the required Microsoft Entra Connect Sync version from 2.5.79.0 to 2.6.84.0 or later and requires application-based authentication by April 7, 2027. Synchronization services will stop if the requirements are unmet.

  • External ID · Authentication
    Entra sign-in will block external script injection in October

    Starting in mid-October 2026, Microsoft Entra ID will enforce a Content Security Policy on login.microsoftonline.com that allows only trusted Microsoft scripts to run. Organizations using tools that inject scripts into the sign-in experience should assess compatibility; no action is indicated if they do not use such tools.

  • Entra ID · Conditional Access
    Agent-user Conditional Access guidance calls out missing all-user coverage

    New guidance says all-user and group targeting do not include agent users. It documents prerequisites, policy targeting, risk controls, device and network conditions, and blocking risky agent-user accounts for agents accessing resources through their own user accounts.

  • Entra ID · Standards
    Entra App Gallery adds self-service app onboarding preview

    ISVs can validate SSO and provisioning integrations, submit and manage applications, and track submission status in the Microsoft Entra admin center. Public preview is available now, with general availability scheduled to begin in mid-November 2026.

For Entra administrators

Prepare external-sharing workflows for Entra B2B guest accounts, verify Connect Sync versions and authentication configuration before the April 7, 2027 deadline, and assess any tools that inject scripts into login.microsoftonline.com. Review agent-user Conditional Access policies for explicit targeting. No action is required for the App Gallery preview unless the organization or its application partners plan to use it.
