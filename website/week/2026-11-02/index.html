Week in brief

Microsoft sets 2027 deadlines for Microsoft-provided SMS and voice retirement

Authentication deadlines are the week’s clearest operational signal: Microsoft is retiring its provided SMS and voice paths for passkey-incompatible sign-ins on staged 2027 dates and for SSPR beginning in February 2027. A new Hard Deletion Protection preview documents a seven-day block on permanent deletion after soft deletion. Global Secure Access pages now direct administrators to keep browser QUIC enabled and use Custom Acquire plus cloud firewall for UDP 443, while Private Access sign-in-every-time has preview deployment guidance. Most other entries are documentation maintenance or expanded procedures.

  • Entra ID · Conditional Access
    Phased retirement targets Microsoft-provided SMS and voice for sign-ins

    For sign-ins that do not support passkeys, users relying only on Microsoft-provided SMS or voice MFA should have a compatible alternative registered by February 1, 2027, for non-admins and July 1, 2027, for admins and external users. Organizations can instead configure customer-managed telephony to avoid sign-in blocks during the phased retirement.

  • Entra ID · Conditional Access
    SSPR SMS and voice recovery enters 50-day transitions in February 2027

    Microsoft-provided SMS and voice authentication for self-service password reset starts retiring in February 2027. Each user group receives a 50-day transition, after which those methods are unavailable, so alternative recovery methods should be prepared before each group’s transition.

  • Entra ID · Security
    Hard Deletion Protection preview guards supported objects for seven days

    The new Microsoft Entra Backup and Recovery guide describes a preview that blocks permanent deletion of supported objects during the first seven days after soft deletion. It requires the Microsoft Entra Backup Administrator role, supports up to 20 objects per type per operation, and covers audit logging and setup.

  • Global Secure Access · General
    Global Secure Access guidance routes UDP 443 through Custom Acquire

    Updated known-limitations guidance says end-to-end QUIC forwarding is unsupported, while cloud firewall QUIC acquisition and blocking are in preview. It directs administrators to keep browser QUIC enabled, use Custom Acquire for UDP 443, and apply a cloud firewall policy through the relevant security profile.

  • Private Access · Conditional Access
    Private Access sign-in-every-time preview adds a controlled rollout path

    The new configuration guide explains how to apply reauthentication to selected private applications with one Conditional Access policy and a pilot group, test it, and deploy it. Global Secure Access Windows client version 2.34.222 or later is required.

For Entra administrators

Separate the SMS and voice work into sign-in and SSPR inventories. Before each applicable 2027 transition, register compatible authentication or recovery methods or configure customer-managed telephony. Review Global Secure Access policies that disable browser QUIC and move to the documented Custom Acquire and cloud-firewall handling where applicable. For the previews, verify the Backup Administrator role, supported objects and operation limits, and use the required Windows client, Conditional Access policy, application scope, and pilot group for Private Access.
