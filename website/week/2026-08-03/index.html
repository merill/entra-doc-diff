Week in brief

MemberOf retirement and authentication migrations define Entra’s week of 3 August 2026

This was a deadline- and behavior-change week rather than a broad feature-launch week. Microsoft announced a November 3, 2026 retirement for MemberOf, an October 27 quarantine behavior for affected ID Governance policies, and a November 9 SSPR enforcement change. SMS and voice MFA also entered a staged transition, while Workload ID administrators received immutable-subject migration guidance for GitHub Actions. The new telephony-provider article is planning guidance, not current provider availability; configuration is not yet available.

  • Entra ID · Conditional Access
    MemberOf operator retirement sets a November 3, 2026 remediation deadline

    Microsoft Entra ID will retire the MemberOf rule operator in dynamic groups, administrative units, and entitlement policies. Configurations that remain unchanged may cause stale access, licensing, and policy-enforcement results, so affected rules need to be identified and replaced before the deadline.

  • ID Governance · Governance
    Entitlement Management will stop processing affected automatic-assignment policies earlier

    Starting October 27, 2026, automatic assignment policies that use memberOf will be quarantined. Assignment processing will stop, with no assignments added or removed until memberOf is removed. Microsoft documents a PowerShell discovery script and recommends rebuilding the rules with a supported attribute-based operator or using an alternative assignment method.

  • Entra ID · Authentication
    SSPR is moving to explicitly registered authentication methods

    Starting November 9, 2026, self-service password reset will require explicitly registered authentication methods and will no longer accept directory-sourced contact information unless it is registered. A registration campaign begins October 5, 2026; administrators should ensure users register methods to avoid reset failures.

  • Entra ID · Authentication
    SMS and voice MFA are on a staged transition path

    The updated authentication guidance says passkeys will be automatically enabled for users using SMS or voice on September 1, 2026. From February 1, 2027, tenants without a customer-managed telecom provider will no longer be able to use SMS or voice for MFA. The timeline applies to the public cloud and excludes Azure AD B2C and Entra External ID.

  • Workload ID · Authentication
    GitHub Actions federated credentials require immutable OIDC subjects

    GitHub Actions now supports immutable OIDC subject formats that include repository and owner IDs. Organizations using GitHub Actions OIDC were instructed to migrate by late July 2026 to avoid token mismatches and reduce unauthorized-access risk; given the stated deadline, administrators should verify completion immediately.

For Entra administrators

Prioritize inventory and remediation: identify MemberOf use in dynamic groups, administrative units, and entitlement policies; address automatic-assignment policies before processing is quarantined; ensure users register SSPR methods; review SMS and voice users and transition options; and verify GitHub Actions federated credentials against the stated migration deadline.
