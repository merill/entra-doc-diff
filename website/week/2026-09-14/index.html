Week in brief

Passkeys become Entra’s default as Microsoft-provided SMS and voice authentication near retirement

Microsoft Entra’s authentication changes dominate the week: passkeys became the default Microsoft Entra authentication on September 1, 2026, while Microsoft-provided SMS and voice authentication are set to retire February 1, 2027. Separate staged changes extend passkeys to B2B users and let users register passkeys or passwordless sign-in as their first MFA method. New External ID guidance documents system-browser handoff for brokered external identity providers, while updated Enterprise State Roaming guidance moves administration away from the Entra admin center.

  • Entra ID · Conditional Access
    Microsoft-provided SMS and voice authentication retire February 1, 2027

    Passkeys became the default Microsoft Entra authentication on September 1, 2026. Microsoft-provided SMS and voice authentication will retire February 1, 2027, requiring customers to use telecom providers from the Microsoft Security Store. Microsoft recommends transitioning to passkeys for stronger, phishing-resistant security.

  • Entra ID · Conditional Access
    B2B users gain passkey registration and sign-in in October rollout

    Microsoft Entra will support passkey registration and sign-in for B2B users beginning in October 2026. Eligible users are automatically enabled, and resource-tenant passkeys provide phishing-resistant MFA. Administrators should review authentication policies and configurations; no immediate action is required.

  • Entra ID · Conditional Access
    Passkeys and passwordless sign-in can become users’ first MFA method

    A phased rollout from October 2026 through February 2027 lets users register passkeys or passwordless sign-in as their first multifactor authentication method, removing the need to establish weaker methods first.

  • External ID · Authentication
    External ID guidance documents system-browser handoff for brokered sign-in

    The new guidance describes handing brokered external-identity-provider authentication from an embedded WebView to the system browser. The flow supports external-IdP passkeys, browser SSO, and identity providers that block WebViews. The article lists supported platforms, brokers, versions, apps, federation protocols, and cloud availability.

  • Entra ID · General
    Enterprise State Roaming management moves out of the Entra admin center

    As of July 2026, Enterprise State Roaming can no longer be managed in the Microsoft Entra admin center. Administrators must use Windows settings backup and restore policies instead; supported settings remain unchanged, and existing controls are honored for one year.

For Entra administrators

Plan the February 1, 2027 replacement for Microsoft-provided SMS and voice authentication using a telecom provider from the Microsoft Security Store; Microsoft recommends transitioning to passkeys for phishing-resistant security. Review B2B authentication policies and configurations as eligible users are automatically enabled, although no immediate action is required. For External ID, verify browser, broker, app-version, federation-protocol, platform, and cloud prerequisites. ESR administrators must use Windows settings backup and restore policies; supported settings remain unchanged and existing controls are honored for one year.
