Week in brief

Entra administrators face November 3 MemberOf retirement and new agent guidance

The week’s clearest operational deadline is Microsoft Entra’s November 3, 2026 retirement of the MemberOf rule operator, requiring replacement in dynamic groups, administrative units, and entitlement policies. Near-term authentication changes include late-October B2B passkey support and an October–November rollout of authenticated password change; the latter is disabled by default and requires administrator activation. Microsoft also published preview lifecycle-policy guidance for Agent ID, while Conditional Access documentation now explicitly separates agent-user targeting from ordinary Users assignments.

  • Entra ID · Conditional Access
    MemberOf rule operator retires November 3, 2026

    Microsoft’s final reminder says organizations must replace MemberOf in dynamic groups, administrative units, and entitlement policies. After November 3, MemberOf-based updates will stop, creating outdated membership, access, and licensing results.

  • Entra ID · Conditional Access
    B2B passkey registration starts in resource tenants late October

    Microsoft Entra ID will support passkey registration and sign-in for B2B users in resource tenants starting in late October 2026. Internal guest users receive Microsoft Authenticator app passkeys, while external users do not. The feature is enabled by default and intersects with SMS and voice retirement policies.

  • Entra ID · Authentication
    Authenticated password change adds a strong-credential recovery path

    During the October–November 2026 global rollout, users who sign in with a passkey, FIDO2 security key, or Windows Hello can change their password without knowing the current password or using self-service password reset. The feature is disabled by default and requires administrator activation.

  • Agent ID · Governance
    Preview guidance details Agent ID lifecycle-policy controls

    A new preview article documents periodic reconfirmation, minimum sponsor requirements, inactivity monitoring, notifications, grace periods, and enforcement actions for agent identities. Administrators can use these controls to govern inactive or orphaned agents and improve sponsor or owner accountability.

  • Agent ID · General
    Conditional Access must target agent users separately

    The updated Agent ID guidance states that policies assigned through Users do not apply to agent user accounts, whether they target all users, selected users, groups, directory roles, or external users. Policies protecting those accounts must select Agents under Users, agents, or workload identities.

For Entra administrators

Replace MemberOf configurations before November 3 and review affected access and licensing dependencies. Review Conditional Access and SMS/voice retirement policies ahead of the B2B passkey rollout. Activate authenticated password change deliberately if required. For agent users, audit existing policies because ordinary Users assignments do not cover them; select Agents instead. The Agent ID lifecycle-policy guidance is preview and states no mandatory action.
