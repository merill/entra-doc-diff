Week in brief

Cloud-to-AD provisioning guidance expands while COOP, telephony, and SCIM deadlines approach

The period's main development is a new Microsoft Entra-to-AD DS provisioning guidance set covering users, groups, memberships, supported flows, and limitations. User provisioning is marked Preview, while group provisioning is generally available. Other high-impact updates document an October ChatWork SCIM retirement, name initial SMS and voice providers ahead of October 30 configuration, and set a January 31, 2027 COOP milestone. The remaining changes are largely reference, metadata, diagram, and procedural refinements.

  • Entra ID · Fundamentals
    Cloud Sync guidance now covers Entra-to-AD DS users and groups

    New overview guidance describes provisioning users, groups, and memberships from Microsoft Entra ID to AD, including supported configurations, user types, attribute updates, enforcement, and provisioning flow. User provisioning is Preview, group provisioning is generally available, and password writeback isn't supported.

  • Entra ID · Authentication
    SMS and voice guidance names Soprano and Telesign as initial providers

    Updated authentication guidance identifies Soprano and Telesign as initial private-preview providers and says provider selection and configuration through Microsoft Security Store begins October 30, 2026. Administrators relying on SMS or voice should evaluate a provider or move affected users to passkeys or another phishing-resistant method before the applicable retirement date.

  • Entra ID · General
    COOP guidance sets a January 31, 2027 app deadline

    New guidance says new applications will be subject to Microsoft Entra COOP policy across web protocols after January 31, 2027. Popup sign-in can fail unless applications use a COOP-compatible flow such as MSAL.js v5; delayed migrations can temporarily opt out through the Microsoft Graph `coopEnforcement` property.

  • Entra ID · Provisioning
    ChatWork SCIM provisioning is scheduled to end October 1

    The Entra provisioning tutorial warns that ChatWork will discontinue SCIM-based provisioning on October 1, 2026, retiring the Entra Enterprise App Gallery integration. Existing customers will no longer be able to provision users after that date and should plan accordingly.

  • Entra ID · Governance
    App Governance permissions will change for select Entra roles

    A Message Center notice says Microsoft Defender for Cloud Apps will update App Governance permissions for the Cloud App Security, Compliance Administrator, and Compliance Data Administrator roles starting in mid-October 2026, aligning them with Defender XDR Unified RBAC. Review and adjust affected role assignments.

For Entra administrators

Prioritize the October dates: affected ChatWork customers should plan for the loss of SCIM provisioning after October 1, 2026, and SMS or voice deployments should evaluate provider options before Microsoft Security Store configuration begins October 30. App owners should test popup sign-in flows before January 31, 2027 and use the documented temporary `coopEnforcement` opt-out only if migration is delayed. Cloud-managed-user deployments must account for unsupported password writeback, and administrators should review the select App Governance role assignments affected by the mid-October RBAC change.

Microsoft-managed CA policy coming to your tenant: Require risk remediation for high-risk users

New

To strengthen your organization's security posture, Microsoft will create a new Microsoft-managed Conditional Access (CA) policy—Require risk remediation for high-risk users—in your tenant, along with a new security group for this policy.
