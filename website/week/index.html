Week in brief

Microsoft Entra CYOT and BYOT reach GA before February 2027 SMS retirement

The week’s main operational development is the general availability of Choose Your Own Telephony Provider and Bring Your Own Telephony Provider for SMS and voice authentication, ahead of Microsoft-provided telephony retiring on February 1, 2027. Microsoft also published a BYOT API deployment guide and new guidance for restricting multitenant app audiences. Security documentation adds concrete proxy requirements for tenant restrictions, while Authenticator passkey resource availability moves to January 2027.

  • Entra ID · Authentication
    CYOT and BYOT become generally available ahead of telephony retirement

    Microsoft Entra now generally supports Choose Your Own Telephony Provider and Bring Your Own Telephony Provider for SMS and voice authentication. Microsoft-provided SMS and voice authentication retires on February 1, 2027, so organizations must transition by that date and should prioritize phishing-resistant methods, using telephony only when necessary.

  • Entra ID · Authentication
    New BYOT guide covers API deployment, policy configuration, and testing

    The new guide explains how to deploy a provider’s BYOT integration in an Azure subscription and configure SMS and voice authentication through Microsoft Graph APIs. It covers prerequisites, permissions, provider-package deployment, policy configuration, and testing with a user.

  • Entra ID · Security
    Multitenant app guidance adds an explicit tenant allowlist control

    New guidance describes requiring multitenant apps to explicitly allow listed tenant IDs, enabling the setting in the Microsoft 365 or Entra admin center, and using reports to identify existing unrestricted apps. Administrators enabling the control should review the impact report before restricting existing app audiences.

  • Entra ID · General
    Tenant restrictions guidance adds sign-in hosts and v2 proxy requirements

    The updated guidance adds Microsoft sign-in host names, states that proxy enforcement requires the tenant restrictions v2 header, and lists device-authentication hosts to exclude from TLS inspection and header injection. Proxy owners should review and test these rules to preserve device authentication.

  • Entra ID · Conditional Access
    Authenticator passkey resource availability moves to January 2027

    The guidance now places availability of the Microsoft Authenticator Credential Registration resource in January 2027 instead of late November 2026. Provisioning its enterprise application remains required before excluding it from a Conditional Access policy, so rollout plans should account for the later date.

For Entra administrators

Organizations using Microsoft-provided SMS or voice authentication should plan a transition before February 1, 2027, while prioritizing phishing-resistant methods. Administrators evaluating BYOT can prepare the provider package, Azure subscription, permissions, policies, and test users. Security teams should review multitenant app impact reports and tenant-restriction proxy rules; passkey rollout plans should use the revised January 2027 availability date.
