Week in brief

Entra administrators face a November 3 deadline to replace MemberOf rules

An urgent MemberOf retirement deadline dominates the week: Microsoft says configurations using the operator in dynamic groups, administrative units, or entitlement policies must be replaced by November 3, 2026. The period also introduces Conditional Access policy plans and an Agent ID inactivity policy in preview, signals the February 1, 2027 retirement of Microsoft-provided SMS and voice authentication, and clarifies that Internet Access cloud firewall policies do not filter DNS traffic in preview.

  • Entra ID · Conditional Access
    MemberOf rule operator retirement reaches its final November 3 deadline

    Microsoft’s final reminder says the MemberOf rule operator will be retired on November 3, 2026. Organizations using it in dynamic groups, administrative units, or entitlement policies must replace those configurations to avoid outdated memberships, access, and licensing issues.

  • Entra ID · Authentication
    Microsoft-provided SMS and voice authentication is scheduled for retirement

    Microsoft will retire Microsoft-provided SMS and voice authentication starting February 1, 2027. Organizations must move users to passkeys or other authentication methods, or configure a customer-managed telecom provider, to avoid sign-in disruptions.

  • Entra ID · Conditional Access
    Conditional Access policy plans preview adds shared targeting and review

    The migration guidance explains how to consolidate selected Conditional Access policies into a policy plan, inspect shared conditions and generated rules, and validate the plan before enforcement. Original policies remain unchanged and continue evaluating independently.

  • Agent ID · Governance
    Agent ID preview policy sets 60-, 90-, and 455-day inactivity milestones

    The documented default inactivity policy notifies owners after 60 days, disables identities after 90 days, and deletes them after 455 days. Administrators can configure scope and fallback notification recipients; seasonal or limited-use agents should be excluded if they must remain inactive.

  • Internet Access · General
    Internet Access guidance says Cloud Firewall does not acquire DNS traffic

    Updated preview guidance states that wildcard acquisition rules and FQDN destinations do not enable DNS acquisition. Cloud Firewall therefore cannot filter DNS queries through this profile; FQDN rules apply to connections to named destinations.

For Entra administrators

Prioritize replacing MemberOf configurations before November 3. Plan SMS and voice authentication migration before February 1, 2027, or configure a customer-managed telecom provider. Treat policy plans and Agent ID inactivity controls as preview capabilities, and do not rely on Internet Access cloud firewall policies for DNS filtering.
