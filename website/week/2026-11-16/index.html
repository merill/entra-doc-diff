Week in brief

Entra sets SMS/voice MFA retirement deadlines as MemberOf updates stop

This week's clearest administrator signals are transition-related: the earlier memberOf preview has frozen, Microsoft has set dates for retiring Microsoft-provided SMS/voice MFA in affected sessions, and risk-based identity verification is now documented as a preview control. SMS/voice also gains a risk-based CAPTCHA step, while Agent ID documents a preview route for OAuth and MCP clients that does not require prior registration. Other supplied changes mainly add how-to and reference coverage for agent fleets, External ID native authentication, and governance workflows.

  • Entra ID · Conditional Access
    SMS/voice MFA retirement sets February and July 2027 preparation deadlines

    Microsoft says users who rely solely on Microsoft-provided SMS/voice MFA in sessions that do not support passkeys must register another method or configure customer-managed telephony. Retirement begins February 1, 2027, or July 1 for administrators and external users; affected users may otherwise face sign-in blocks.

  • Entra ID · General
    The earlier memberOf preview leaves dynamic assignments at their last state

    Updated Entra guidance records that the earlier memberOf preview ended on November 3, 2026. Dynamic groups, dynamic administrative units, and entitlement management auto-assignment policies using it stop updating and remain at their last known state; Microsoft directs administrators to MemberOf Next.

  • ID Protection · Conditional Access
    Risk-based policy guidance now covers Require Identity Verification in preview

    The updated ID Protection guidance describes Require Identity Verification for Conditional Access policies with User risk or Sign-in risk. It requires an identity verification profile and supported credential; successful verification remediates the applicable risk, while failed verification does not.

  • Entra ID · Authentication
    Risk-based CAPTCHA now gates some SMS and voice MFA delivery

    Microsoft says Entra will add risk-based CAPTCHA for SMS and voice MFA starting in mid-November 2026. Some users may need to complete CAPTCHA before receiving a code or call, as Microsoft targets automated fraud.

  • Agent ID · Standards
    Agent ID preview uses public metadata URLs for unregistered OAuth clients

    The new guide explains publishing a Client ID Metadata Document at a public HTTPS URL and using that URL as an OAuth or MCP client ID to request delegated Entra tokens without prior registration. The preview requires authorization code flow with PKCE, may require administrator consent, has no service-level agreement, and is not recommended for production workloads.

For Entra administrators

Prioritize an inventory of earlier memberOf configurations and migrate them to MemberOf Next. For MFA, identify users who rely solely on SMS/voice, provide alternative methods or customer-managed telephony, and prepare help-desk communications and network readiness for CAPTCHA. Validate the identity-verification profile and credential prerequisites before testing the risk control, and keep the Agent ID metadata-document path out of production while its preview limitations and consent requirements are reviewed.
