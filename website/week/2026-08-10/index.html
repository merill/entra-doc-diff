Week in brief

Microsoft Entra will roll out passkeys as users’ first MFA method

The clearest product news is a Microsoft Entra rollout allowing passkeys or other passwordless sign-in methods as users’ first multifactor authentication method, scheduled from October 2026 through February 2027. Microsoft also announced September general availability for on-behalf-of ordering with Entra External ID in Dynamics 365 Commerce. Most other changes are documentation clarifications, including Token Protection browser support in Preview, the Global Secure Access web-filtering V2 model, and Agent ID OAuth requirements.

  • Entra ID · Conditional Access
    Passkeys can be users’ first multifactor authentication method

    A Microsoft 365 Message Center notice says users can register passkeys or passwordless sign-in as their first multifactor authentication method, removing the need to configure weaker methods first. The change is scheduled to roll out from October 2026 through February 2027, and the notice says no administrator action is required.

  • External ID · General
    Entra External ID on-behalf-of ordering is scheduled for Commerce GA

    Microsoft announced the ability to enable on-behalf-of ordering for Entra External ID in Dynamics 365 Commerce, with general availability scheduled for September 11, 2026. The supplied notice does not specify an administrator action.

  • Entra ID · Fundamentals
    Token Protection guidance covers browser-based Azure Resource Manager access in Preview

    The updated Token Protection article now documents Preview support for selected browser-based web applications accessing Azure Resource Manager on Windows and macOS, while iOS and iPadOS browser support is not supported. It also adds browser, extension, operating-system, and configuration requirements; enforcement uses the Windows Azure Service Management API resource in Conditional Access.

  • Internet Access · Fundamentals
    Global Secure Access documents the V2 web-filtering policy model

    A new concept article—not a launch announcement—describes Microsoft Entra Internet Access web-filtering V2: one policy per security profile, multiple rules with individual actions, a default action, and FQDN destinations configured as URLs. Existing V1 web-content-filtering policies continue to function until migration; no migration deadline is stated.

  • Agent ID · Standards
    Agent ID OAuth guidance clarifies audiences and preauthorized permissions

    Updated Agent ID guidance states that Tc must target the agent identity blueprint, while T1 targets the token-exchange resource and is validated against the blueprint and child identity. It also clarifies that child agent identities cannot initiate interactive authorization flows and require delegated permissions preauthorized through inheritable blueprint permissions. This is a clarification of protocol requirements, not an announced new feature.

For Entra administrators

The passkey notice says no administrator action is required, but teams should track the rollout if they manage authentication journeys. External ID and Dynamics 365 Commerce teams should note the September 11, 2026, general availability date. Administrators evaluating Token Protection, Internet Access web filtering, or Agent ID should use the newly documented prerequisites, policy model, audiences, and permission requirements. The evidence does not support a broad tenant-wide action.
