GitHub API access

The diff viewer reads public documentation revisions from GitHub. Without a token, GitHub allows only 60 API requests per hour for each public IP address. One comparison normally uses three requests.

GitHub’s hourly limit was reached

The shared unauthenticated allowance has been used. Add a token below to continue with your personal GitHub API allowance.

How to create one

  1. Open GitHub’s fine-grained token form ↗.
  2. Choose a short expiration and your own account as the resource owner.
  3. No additional repository permissions are required for these public documentation repositories.
  4. Generate the token, then paste and save it here.

The token is saved only in this browser and sent only to api.github.com. Treat it like a password and use the shortest practical expiration.
