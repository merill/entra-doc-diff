8 October 2026

Microsoft Entra ID: Passkey support for B2B users

Message CenterMC1459133 on mc.merill.net ↗Stay informed
Conditional Access

Microsoft Entra ID will support passkey registration and sign-in for B2B users, enabling phishing-resistant MFA in resource tenants starting late October 2026. Internal guest users get Microsoft Authenticator app passkeys; external users do not. The feature is enabled by default, intersecting with SMS/voice retirement policies. No action required, but administrators should review policies.

8 October 2026

Microsoft Entra: Users can register a passkey or passwordless sign-in as their first multifactor authentication method

Message CenterMC1450133 on mc.merill.net ↗Stay informed
Conditional Access

Microsoft Entra will allow users to register passkeys or passwordless sign-in as their first multifactor authentication method, removing the need to set up SMS or voice first. This phased rollout begins late October 2026, aiming to ease adoption of phishing-resistant authentication without requiring user action.

Microsoft Entra: Authenticated password change in My Sign-Ins

Message CenterMC1437671 on mc.merill.net ↗Stay informed
Authentication

Microsoft Entra will enable authenticated password changes in My Sign-Ins starting mid-October 2026. Users with strong credentials (passkey, FIDO2 key, Windows Hello) can reset passwords without knowing the current one or using SSPR. The feature is off by default and requires admin activation tenant-wide.

Microsoft Entra ID: Final reminder to replace MemberOf rule operator configurations by November 3, 2026

Message CenterMC1488834 on mc.merill.net ↗Plan for change
Conditional Access

Microsoft Entra ID will retire the MemberOf rule operator by November 3, 2026. Organizations must replace MemberOf in dynamic groups, administrative units, and entitlement policies to avoid outdated memberships, access, and licensing issues. After this date, MemberOf-based updates will stop, impacting Conditional Access and related services.
