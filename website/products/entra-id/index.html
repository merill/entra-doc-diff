Microsoft Entra ID: Passkey support for B2B users

Message CenterMC1459133 on mc.merill.net ↗Stay informed
Conditional Access

Microsoft Entra ID will support passkey registration and sign-in for B2B users, enabling phishing-resistant MFA in resource tenants starting late October 2026.
