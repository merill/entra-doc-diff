Microsoft Entra ID: Reminder to migrate from Microsoft-provided SMS and voice authentication

Message CenterMC1528000 on mc.merill.net ↗Major updatePlan for change
Authentication

Microsoft Entra ID will retire Microsoft-provided SMS and voice authentication starting February 1, 2027. Organizations must migrate users to passkeys or other methods, or configure a customer-managed telecom provider before then to avoid sign-in disruptions. SMS and voice are vulnerable to attacks; passkeys are recommended.
