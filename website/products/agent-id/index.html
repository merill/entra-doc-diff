Action may be required: Review who can create agents in Microsoft Entra

Message CenterMC1506733 on mc.merill.net ↗Plan for change
Microsoft identity platform

Starting November 4, 2026, default users in Microsoft Entra can create agent blueprints unless administrators disable this via the "Users can create agent blueprints" setting. Admins can restrict this by toggling the setting to No in the Entra admin center before rollout completes in late November.

13 October 2026

Microsoft Entra: Changes to AgentIdentity.CreateAsManager permission for agent identities

Message CenterMC1506728 on mc.merill.net ↗Plan for change
Authentication

Starting November 4, Microsoft Entra will stop automatically granting the AgentIdentity.CreateAsManager permission to agent blueprints. Admin consent will be required for agents to create identities. This change, rolling out worldwide in November 2026, enhances control and auditability of agent identity creation.

Agent Owners Sponsors Managers

General

In Microsoft Agent ID, the agent's identity, blueprint, and blueprint principal may all have sponsors associated with them. In addition, agents can have an [agent's user account](agent-users.md) created in order to access user-oriented services. While the Entra user has a sponsor relationship, there are differences between the user account sponsors and sponsors of the agent identity, blueprint, or blueprint principal.
