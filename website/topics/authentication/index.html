Microsoft Entra: Allow password change after secure sign-in with My Sign-Ins

Message CenterMC1437671 on mc.merill.net ↗Stay informed
Authentication

Microsoft Entra will enable users to change passwords after secure sign-in using strong credentials (passkey, FIDO2, Windows Hello) without knowing the current password or using SSPR.
