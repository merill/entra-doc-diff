10 October 2024

Microsoft Edge Mobile: Updated Weather and Wallpaper on the New tab page (Microsoft Entra ID users)

Message CenterMC907533 on mc.merill.net ↗Plan for change
Branding

Microsoft Edge Mobile will soon update the New tab page for Microsoft Entra ID users with default Wallpaper and Weather features. Wallpaper will be enabled by default, and a weather icon will be added. Rollouts for these features are expected in early and late October 2024, respectively. No admin action is required before the rollout.
