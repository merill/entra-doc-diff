Month in brief

SMS and voice retirement deadlines reshape Entra authentication planning for 2027

November’s operational signal is a split retirement of Microsoft-provided SMS and voice: passkey-incompatible sign-ins move to staged 2027 deadlines, while SSPR has its own February transition. A GoTo OAuth-grant retirement creates a March 31 provisioning deadline. Global Secure Access guidance now centers on keeping QUIC enabled, and new Hard Deletion Protection preview guidance documents a seven-day safeguard after soft deletion. Beyond these items, much of the period consisted of link, terminology, and troubleshooting maintenance.

  • Entra ID · Conditional Access
    Microsoft-provided SMS and voice MFA retirement gets staged 2027 deadlines

    For sign-ins that do not support passkeys, users relying solely on Microsoft-provided SMS or voice MFA must register compatible alternatives or configure customer-managed telephony by February 1, 2027 for non-admins and July 1, 2027 for admins and external users, or risk sign-in blocks during phased retirement.

  • Entra ID · Conditional Access
    SSPR SMS and voice authentication enters a separate February transition

    Microsoft-provided SMS and voice authentication for self-service password reset will begin retiring in February 2027, with a 50-day transition for each user group. After its transition, a group will need alternative recovery methods because Microsoft-provided SMS and voice will no longer be available for SSPR.

  • Entra ID · Provisioning
    GoTo provisioning must move from Authorization Code to Client Credentials

    The GoTo provisioning guidance now directs administrators to create an OAuth client and use Client Credentials Grant because Authorization Code Grant is being retired. Migrate affected jobs by March 31, 2027 using the GoTo client ID, client secret, and token endpoint; otherwise user and group synchronization may stop while SSO remains unaffected.

  • Global Secure Access · General
    Global Secure Access guidance keeps browser QUIC enabled for UDP 443 handling

    Updated Windows client guidance directs administrators to use Custom Acquire for UDP 443 and a cloud firewall Block rule while keeping browser QUIC enabled. DNS over HTTPS must remain disabled for FQDN-based acquisition. QUIC acquisition and blocking are in preview, and the guidance states that they do not provide end-to-end QUIC forwarding.

  • Entra ID · Security
    Hard Deletion Protection preview documents a seven-day recovery safeguard

    New preview guidance describes blocking permanent deletion of supported Microsoft Entra objects during the first seven days after soft deletion. Configuration requires the Microsoft Entra Backup Administrator role, supports up to 20 objects per type per operation, and includes audit logging guidance.

For Entra administrators

Inventory Microsoft-provided telephony dependencies separately for sign-in and SSPR. Prepare alternative methods or customer-managed telephony, migrate affected GoTo provisioning jobs, and review Global Secure Access policies that disable browser QUIC where applicable. For Hard Deletion Protection, confirm the Backup Administrator role, supported object types, and operation limits before testing the preview.
