Month in brief

SPO OTP retirement and MemberOf deadline reshape October Entra administration

October’s most consequential changes were two administrator deadlines: SharePoint One-Time Passcode authentication begins retiring in mid-October, moving external sharing to Microsoft Entra B2B guest accounts, while the MemberOf rule operator retires on November 3. Microsoft also extended the Entra Connect Sync minimum-version deadline, published detailed Conditional Access guidance for agent users, and clarified separately enabled device synchronization for Cloud Sync hybrid join. Most remaining updates were documentation maintenance or narrower guidance refinements.

  • External ID · Conditional Access
    SharePoint One-Time Passcode retirement moves external sharing to Entra B2B

    SharePoint One-Time Passcode authentication begins retiring in mid-October 2026 across Microsoft 365 tenants. External users will instead use Microsoft Entra B2B guest accounts, bringing SharePoint and OneDrive sharing into the B2B governance and Conditional Access model.

  • Entra ID · Conditional Access
    MemberOf rule operator retires November 3, 2026

    Microsoft Entra will retire MemberOf on November 3. Organizations must replace it in dynamic groups, administrative units, and entitlement policies; afterward, MemberOf-based updates will stop, potentially leaving memberships, access, licensing, and related Conditional Access outcomes outdated.

  • Entra ID · Conditional Access
    Agent-user Conditional Access guidance requires separate targeting

    The new guidance documents agent-risk, compliant-device, and compliant-network policies, along with agent-specific targeting and prerequisites. It explicitly states that existing policies targeting all users do not include agent user accounts.

  • Entra ID · Provisioning
    Connect Sync minimum-version deadline extends to April 7, 2027

    The minimum-version deadline moved from September 30, 2026, to April 7, 2027. Microsoft Entra Connect Sync 2.5.79.0 or later is required; synchronization services will fail until an upgrade is completed if the requirement is missed.

  • Entra ID · Provisioning
    Cloud Sync guidance adds separately enabled device synchronization for hybrid join

    The migration decision guide now states that Cloud Sync supports device synchronization for Microsoft Entra hybrid join. Device synchronization must be enabled separately, so migration plans and configuration steps need to account for it when applicable.

For Entra administrators

Plan for guest-account-based SharePoint and OneDrive external access, replace MemberOf configurations before November 3, and verify that Entra Connect Sync meets the 2.5.79.0 minimum before April 7, 2027. Review Conditional Access policies separately for agent user accounts, and enable Cloud Sync device synchronization separately when migrating Microsoft Entra hybrid-joined devices.
