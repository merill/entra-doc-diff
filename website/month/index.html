Month in brief

Entra moves external sharing to B2B as telephony and agent controls tighten

October’s most consequential Entra changes are scheduled retirements and control changes: SharePoint One-Time Passcode authentication begins retiring in favor of Microsoft Entra B2B, Microsoft-provided SMS and voice authentication enters a provider transition, and two Agent ID permission controls change in November. Entra also sets a final deadline for replacing MemberOf configurations.

  • External ID · Conditional Access
    SharePoint OTP gives way to Microsoft Entra B2B

    SharePoint One-Time Passcode authentication starts retiring in mid-October 2026 across Microsoft 365 tenants. External sharing and authentication move to Microsoft Entra B2B, requiring guest accounts for external users and enabling Conditional Access governance across SharePoint and OneDrive.

  • Entra ID · Authentication
    Entra opens SMS and voice authentication to selected providers

    Starting October 30, organizations can choose a supported third-party telephony provider through Microsoft Security Store. Microsoft-provided SMS and voice authentication retires by February 1, 2027, except for some users until July 1, 2027; organizations manage provider relationships directly.

  • Entra ID · Conditional Access
    MemberOf rule configurations reach a November 3 cutoff

    Microsoft Entra will retire the MemberOf rule operator on November 3, 2026. Organizations must replace it in dynamic groups, administrative units, and entitlement policies because MemberOf-based updates will stop afterward, affecting memberships, access, and licensing.

  • Agent ID · Microsoft identity platform
    Agent-blueprint creation becomes an explicit tenant control

    Starting November 4, default users can create agent blueprints unless administrators disable the “Users can create agent blueprints” setting. Administrators can set it to No in the Entra admin center before rollout completes in late November.

  • Agent ID · Authentication
    Agent identity creation will require administrator consent

    Starting November 4, Microsoft Entra will stop automatically granting the AgentIdentity.CreateAsManager permission to agent blueprints. Agents that create identities will require administrator consent, strengthening control and auditability of agent identity creation.

For Entra administrators

Prepare external-sharing workflows for B2B guest accounts, select a supported telephony provider before Microsoft-provided SMS and voice authentication retires, replace MemberOf configurations by November 3, and review agent-blueprint creation and identity-creation consent settings before the November 4 rollout.
