Month in brief

Viva Engage will require Entra roles for community administration from late September

September’s most consequential Entra change is a Viva Engage access-policy deadline: community and membership management will require the Yammer Administrator role or a Community Admin assignment from late September 2026. Other meaningful developments include a Global Secure Access preview for Microsoft-managed TLS certificates, explicit Entra SOC Identity Responder containment permissions, a documented 98% managed-identity quota threshold, and clearer passkey registration-campaign states and prerequisites. Most remaining activity was documentation maintenance.

  • Entra ID · Security
    Viva Engage shifts community and membership tasks to Entra permissions

    From late September 2026, community and membership management will require either the Yammer Administrator role or a Community Admin assignment. Verified and Network Admins previously had access, so administrators should review and update role assignments.

  • Global Secure Access · Security
    Global Secure Access previews Microsoft-managed roots for TLS inspection

    The new guide describes creating a tenant-specific Microsoft-managed root CA, deploying its public certificate to client devices, and then enabling it for Microsoft Entra Internet Access TLS inspection. The private key remains protected by Microsoft, and MDM such as Intune can handle certificate deployment.

  • Entra ID · General
    Entra SOC Identity Responder containment actions are now spelled out

    The updated permissions reference lists disabling users, revoking active sign-in sessions, and resetting passwords as identity-containment actions for the Entra SOC Identity Responder role. Use the reference when evaluating least-privilege incident-response assignments.

  • Workload ID · General
    Managed identity guidance sets a 98% directory-quota threshold

    The FAQ now says creation or recreation of a managed-identity service principal is blocked when resulting directory usage reaches or exceeds 98% of tenant quota. Existing identities and assignments continue to work, while soft-deleted objects count; reducing usage or increasing the quota enables retries.

  • Entra ID · Authentication
    Registration-campaign guidance distinguishes states and method-specific prerequisites

    The updated page separates Microsoft managed, Enabled, and Disabled campaign states and documents eligibility, prompting conditions, and prerequisites for Authenticator and passkey campaigns. The updated experience is rolling out through the end of September 2026, so tenant behavior may vary during rollout.

For Entra administrators

Review Viva Engage role assignments before late September. For the TLS inspection preview, deploy the Microsoft-managed root CA public certificate to client devices before enabling inspection. Review SOC incident-response delegation, monitor directory usage—including soft-deleted objects—before creating or recreating managed identities, and check passkey campaign prerequisites and rollout status.
