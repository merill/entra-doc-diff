Month in brief

SharePoint OTP retirement shifts external sharing to Entra B2B amid Connect hardening

October’s clearest operational change is the mid-October 2026 retirement of SharePoint One-Time Passcode authentication across Microsoft 365, moving external sharing and authentication to Microsoft Entra B2B guest accounts. Connect guidance also changed materially: one page moves the minimum-version deadline to April 7, 2027, while another requires Connect 2.6.84.0 or later plus application-based authentication for its AD FS/PingFederate scenario. The App Gallery added public-preview self-service onboarding for ISVs, while other substantive documentation covered guest lifecycle workflows and app-lock scope; most remaining edits were terminology, CSV, path, and example maintenance.

  • External ID · Conditional Access
    SharePoint One-Time Passcode authentication begins retiring in mid-October

    The External ID message says SharePoint One-Time Passcode authentication will retire starting in mid-October 2026 for all Microsoft 365 tenants, with external sharing and authentication transitioning to Microsoft Entra B2B. External users will require guest accounts, bringing SharePoint and OneDrive under the B2B governance and Conditional Access model.

  • Entra ID · Standards
    App Gallery opens self-service onboarding to ISVs

    Microsoft Entra App Gallery now lets ISVs validate SSO and provisioning integrations, manage submissions, and track status through the Microsoft Entra admin center. Public preview is available now, with general availability beginning in mid-November 2026; the notice says no tenant action is required.

  • Entra ID · Provisioning
    Connect Sync minimum-version deadline moves to April 7, 2027

    The updated hardening guidance extends the minimum-version deadline from September 30, 2026, to April 7, 2027, and requires Microsoft Entra Connect Sync version 2.5.79.0 or later. The page says synchronization services will fail until the upgrade is completed.

  • Workload ID · Provisioning
    AD FS and PingFederate hardening now requires Connect 2.6.84.0

    For the documented AD FS/PingFederate scenario, the required Microsoft Entra Connect version changed from 2.5.79.0 to 2.6.84.0 or later. The guidance also now requires application-based authentication to maintain directory synchronization and avoid service disruptions.

  • Entra ID · Security
    App instance lock guidance now covers single-tenant applications

    The configuration guide states that locks apply to an application’s service principal for both single-tenant and multitenant applications. It also records Enable property lock as enabled by default for new applications since June 2026 and directs administrators to manage the setting through servicePrincipalLockConfiguration.

For Entra administrators

Prepare SharePoint and OneDrive external-sharing workflows for B2B guest accounts, including the associated governance and Conditional Access model. Inventory Connect deployments against the applicable guidance: the Sync page requires version 2.5.79.0 or later by April 7, 2027, while the AD FS/PingFederate hardening guide requires 2.6.84.0 or later and application-based authentication. The App Gallery notice says no tenant action is required; administrators should review app instance lock settings and protected service-principal properties for both single-tenant and multitenant applications.
