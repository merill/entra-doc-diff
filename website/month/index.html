Month in brief

Custom branding CSS, SMS sign-in, and MemberOf retirements set Entra deadlines

August’s most consequential Entra changes are deadline-driven. Custom CSS layout and positioning properties in company branding are blocked for new use from July 21 and retire in late October; SMS first-factor sign-in for Entra ID Free tenants is scheduled for retirement on August 11; and public-cloud SMS and voice guidance sets automatic passkey enablement on September 1 and an MFA cutoff on February 1, 2027, for tenants without customer-managed telecom providers. MemberOf rules are slated for retirement on November 3, while SSPR will require explicitly registered methods from November 9 after a registration campaign begins October 5. First-factor system-preferred authentication is also rolling out to Microsoft-managed tenants through late September. Additional guidance details Tenant Governance snapshots for configuration baselines or audit evidence, configuration monitors for drift, and a guided Global Secure Access V1-to-V2 web-content-filtering migration.

  • Entra ID · Authentication
    Company branding loses custom CSS layout controls

    New use of custom CSS layout and positioning properties is blocked from July 21, 2026. Microsoft plans to retire the properties by late October, after which branding configurations that use them will revert to default layouts. Administrators should update affected configurations before retirement.

  • Entra ID · Authentication
    SMS first-factor sign-in exits Entra ID Free tenants

    Microsoft will retire SMS first-factor sign-in for Microsoft Entra ID Free tenants on August 11, 2026, because of fraud risks. Users must switch to another authentication method; SMS used as a multifactor method remains unaffected. Administrators should identify affected users and update authentication policies.

  • Entra ID · Authentication
    Public-cloud SMS and voice MFA face a two-step transition

    Updated guidance says passkeys will be automatically enabled for users using SMS or voice on September 1, 2026. From February 1, 2027, tenants without a customer-managed telecom provider will no longer be able to use SMS or voice for MFA. The timeline applies to public cloud and excludes Azure AD B2C and Microsoft Entra External ID.

  • Entra ID · Conditional Access
    MemberOf rules require replacement by November 3

    Microsoft will retire the MemberOf rule operator on November 3, 2026. Replace it in dynamic groups, administrative units, and entitlement policies to avoid stale access, licensing, and policy-enforcement outcomes.

  • Entra ID · Authentication
    SSPR moves to explicitly registered authentication methods

    Starting November 9, 2026, SSPR verification will require explicitly registered authentication methods; directory-sourced contact information won't qualify unless it is registered. A registration campaign begins October 5, 2026, so administrators should ensure users register suitable methods before enforcement.

For Entra administrators

Prioritize remediation and user-readiness work: audit company-branding configurations for affected CSS properties; identify Entra ID Free users who rely on SMS first-factor sign-in; and plan the documented passkey, opt-out, customer-managed-provider, or alternative-method paths for public-cloud SMS and voice users. Replace MemberOf rules in dynamic groups, administrative units, and entitlement policies before November 3. Prepare users for SSPR registration before the October 5 campaign and November 9 enforcement date. Review first-factor system-preferred authentication settings and user guidance. Teams adopting Tenant Governance workflows should verify Basic or Premium licensing, quota, privileged-role and read permissions, and Tenant Configuration Management service authorization.
