Month in brief

Microsoft Entra Connect hardening adds application authentication as deadline shifts to April 2027

October’s four supplied items are all Microsoft Learn documentation updates. The consequential changes affect Microsoft Entra Connect guidance: the AD FS/PingFederate hardening page now calls for version 2.6.84.0 or later and application-based authentication, while the Connect Sync hardening page moves its minimum-version deadline from September 30, 2026, to April 7, 2027, with version 2.5.79.0 or later still required. The other revisions standardize Zscaler names and setup references.

  • Workload ID · Provisioning
    AD FS/PingFederate hardening raises the Connect version requirement

    The updated guidance changes the required Microsoft Entra Connect version from 2.5.79.0 to 2.6.84.0 or later and adds application-based authentication to maintain directory synchronization and avoid service disruptions.

  • Entra ID · Provisioning
    Connect Sync upgrade deadline moves to April 7, 2027

    The minimum-version deadline changes from September 30, 2026, to April 7, 2027. Microsoft Entra Connect Sync version 2.5.79.0 or later remains required, and synchronization services fail until the upgrade is completed if the requirement is not met.

  • Entra ID · Authentication
    Zscaler Authentication Service replaces legacy provisioning terminology

    The provisioning tutorial replaces references to Zidentity and Zscaler Provisioning with Zscaler Authentication Service and updates the related titles, prerequisites, app-role guidance, and provisioning steps.

  • Entra ID · Provisioning
    Zscaler ZNet terminology is standardized across the provisioning guide

    The guide now consistently identifies the application, tenant, SCIM API, and gallery entry as Zscaler ZNet. Existing configurations do not require changes.

For Entra administrators

Apply the guidance that matches the deployment: AD FS/PingFederate hardening now calls for Microsoft Entra Connect 2.6.84.0 or later and application-based authentication by the stated deadline. The separate Connect Sync hardening page allows version 2.5.79.0 or later until April 7, 2027; synchronization services will fail until an upgrade is completed if the minimum is not met. Administrators following the Zscaler tutorials should use the updated service names, while existing Zscaler ZNet configurations require no action.
