Month in brief

August 2026: MemberOf retirement and authentication-enforcement deadlines lead the Entra agenda

The month’s most consequential changes are scheduled retirements and behavior changes rather than confirmed feature launches. Microsoft Entra ID will retire the MemberOf rule operator by November 3, 2026; SSPR will require explicitly registered authentication methods from November 9; and Microsoft-provided SMS and voice MFA is moving toward passkeys and customer-managed telephony. Workload ID administrators also face a security migration for GitHub Actions federated credentials. Other notable additions, including Tenant Governance snapshots and monitoring guidance, are documentation and planning material; the supplied evidence does not establish a new general-availability launch. The new telephony-provider guidance likewise says providers are not yet available to configure.

  • Entra ID · Conditional Access
    MemberOf rule operator retirement requires configuration changes

    Microsoft Entra ID plans to retire the MemberOf rule operator on November 3, 2026. The affected scope includes dynamic groups, administrative units, and entitlement policies. Administrators should replace these rules before the deadline to avoid stale access, licensing, and policy-enforcement results. This is a retirement and migration requirement, not a new feature launch.

  • ID Governance · Governance
    Automatic assignment policies using MemberOf will be quarantined

    Starting October 27, 2026, automatic assignment policies in entitlement management that use MemberOf will be quarantined. Assignment processing will stop, so no assignments will be added or removed until MemberOf is removed. The updated guidance points administrators to a PowerShell discovery script and supported attribute-based alternatives. This is a scheduled behavior change within ID Governance.

  • Entra ID · Authentication
    SSPR is moving to explicitly registered authentication methods

    Beginning November 9, 2026, Microsoft Entra self-service password reset will no longer accept directory-sourced contact information unless the method is explicitly registered. A registration campaign begins October 5, 2026. Administrators need to ensure users register acceptable methods before enforcement to avoid password-reset failures.

  • Entra ID · Authentication
    SMS and voice MFA face a staged public-cloud retirement

    Updated guidance says passkeys will be automatically enabled for users using SMS or voice on September 1, 2026. From February 1, 2027, public-cloud tenants without a customer-managed telecom provider will no longer be able to use SMS or voice for MFA. Azure AD B2C and Entra External ID are excluded. Administrators should review affected users and plan migration, a documented temporary opt-out, or a customer-managed provider.

  • Workload ID · Authentication
    GitHub Actions federated credentials require immutable OIDC subjects

    GitHub Actions now supports immutable OIDC subject formats based on repository and owner IDs. Organizations using GitHub Actions federation with Microsoft Entra were told to migrate by late July 2026 to avoid token mismatches and reduce unauthorized-access risk. Because that deadline predates this monthly review, administrators should audit affected Workload ID credentials immediately.

For Entra administrators

Prioritize inventory and migration work: find and replace MemberOf rules, including affected entitlement-management policies; update SSPR registration campaigns and user communications; identify users dependent on SMS or voice MFA and plan passkey, provider, or documented opt-out paths; and audit GitHub Actions federated credentials because the stated migration deadline was in late July 2026. Treat the Tenant Governance and tenant-architecture additions as guidance to review rather than evidence of a new GA service rollout.
