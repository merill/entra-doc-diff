Month in brief

MemberOf retirement and authentication deadlines put Entra administrators on notice

August's consequential Entra changes center on retirements and tightening defaults. Microsoft scheduled MemberOf rule retirement for November 3, 2026; SMS first-factor sign-in for Microsoft Entra ID Free tenants for August 11; public-cloud SMS and voice guidance sets September 1 passkey enablement and a February 1, 2027 cutoff without a customer-managed telecom provider; and SSPR's registered-method requirement starts November 9 after an October 5 registration campaign. Federated sign-in validation is also tightening for older configurations. Outside these deadlines, Global Secure Access V1-to-V2 migration guidance and Tenant Governance snapshot and monitor procedures were the clearest operational additions.

  • Entra ID · Conditional Access
    MemberOf rules face a November 3 retirement deadline

    Microsoft Entra ID will retire the MemberOf rule operator on November 3, 2026. The affected configurations include dynamic groups, administrative units, and entitlement policies; replacement work is needed to avoid stale access, licensing, and policy-enforcement results.

  • Entra ID · Authentication
    SMS first-factor sign-in retires for Entra ID Free tenants

    Microsoft scheduled SMS first-factor sign-in retirement for Microsoft Entra ID Free tenants on August 11, 2026 because of fraud risks. Users must move to another authentication method, while SMS used as a multifactor method remains unaffected.

  • Entra ID · Authentication
    Public-cloud SMS and voice MFA enter a staged phase-out

    Updated guidance says passkeys will be automatically enabled for users using SMS or voice on September 1, 2026. From February 1, 2027, tenants without a customer-managed telecom provider will no longer be able to use SMS or voice for MFA. The timeline applies to public cloud and excludes Azure AD B2C and Microsoft Entra External ID.

  • Entra ID · Authentication
    SSPR will require explicitly registered authentication methods

    Starting November 9, 2026, Microsoft Entra ID self-service password reset will require explicitly registered authentication methods for verification. Directory-sourced contact information will not qualify unless registered; a registration campaign begins October 5, 2026.

  • External ID · Conditional Access
    Federated sign-in validation tightens for legacy domain configurations

    Microsoft announced a mid-August update to the default federatedTokenValidationPolicy. It blocks federated sign-ins when internalDomainFederation does not match the user's UPN domain, affecting federated domains configured before December 2025. Microsoft Graph customization is available but discouraged.

For Entra administrators

Inventory and replace MemberOf rules in dynamic groups, administrative units, and entitlement policies before November 3. Identify Free-tenant users relying on SMS first-factor sign-in separately from users using SMS for MFA, which remains unaffected by that retirement. For public-cloud tenants, plan the September passkey transition and February 2027 SMS/voice cutoff, or use the documented opt-out while configuring a customer-managed provider or migrating users. Drive SSPR method registration ahead of November 9 and review federated domains configured before December 2025 for internalDomainFederation and UPN root-domain mismatches.
