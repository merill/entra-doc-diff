Month in brief

Tenant MFA deadline is September’s key Entra action; FIDO2 provisioning APIs enter public preview

The supplied September activity consists of two Microsoft 365 Message Center notices for Entra ID, both focused on authentication. The immediate operational requirement is to enable tenant MFA by October 15, 2024, for access to the Microsoft Azure portal, Microsoft Entra admin center, and Microsoft Intune admin center. Separately, FIDO2 provisioning APIs entered public preview, with rollout scheduled from mid- to late September. No supplied item reports a generally available release, retirement, or documentation change.

  • Entra ID · Authentication
    Tenant MFA deadline for administrative access

    The September 14 action notice asks organizations to enable MFA for the tenant by October 15, 2024, to access the Microsoft Azure portal, Microsoft Entra admin center, and Microsoft Intune admin center. This is a time-bound administrative requirement, not a new product launch.

  • Entra ID
    Admins without MFA will be prompted to register at sign-in

    The notice states that administrators signing in without MFA will be prompted to register for it. This changes the administrative sign-in experience, although the supplied evidence does not state that access will be blocked outright.

  • Entra ID · Authentication
    FIDO2 provisioning APIs move to public preview

    The APIs are intended to pre-provision FIDO2 security keys for users, simplifying onboarding and supporting phishing-resistant authentication. Rollout was scheduled to begin in mid-September and finish by late September 2024; no administrator action was required for the rollout, and the capability remains a public preview.

For Entra administrators

Prioritize tenant MFA readiness before October 15. Postponement is possible, but administrators who sign in without MFA will be prompted to register, changing the sign-in experience for the named admin centers. The FIDO2 API rollout requires no administrator action; the supplied notice provides no configuration, eligibility, or migration requirements, and the capability should be treated as a preview rather than as generally available.
