Take action: Enable multifactor authentication for your tenant before October 15, 2024

New

Enable multifactor authentication (MFA) for your tenant by October 15, 2024, to access Microsoft Azure portal, Microsoft Entra admin center, and Microsoft Intune admin center. Postponement is possible, but without MFA, admin sign-in will prompt MFA registration.

Public Preview: Microsoft Entra ID FIDO2 provisioning APIs

New

Microsoft Entra ID introduces FIDO2 provisioning APIs in public preview, enabling pre-provisioning of security keys for users, simplifying onboarding, and ensuring phishing-resistant authentication. Rollout begins mid-September 2024, with completion by late September. No admin action is required for the rollout.
