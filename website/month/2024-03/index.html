March 2024: Entra consent administration shifts to new Teams controls and the Entra portal as legacy interfaces retire

March’s supplied Entra record consists of Microsoft 365 Message Center notices rather than documentation changes. The main operational theme is consent control migration: Teams and chat resource-specific consent settings are rolling out while legacy Group owner and Chat RSC interfaces retire, and the tenant-wide user-consent setting is leaving the Microsoft 365 admin center for the Entra portal. The other notices cover Entra PIM in public preview in the Power Platform admin center and changed Copilot welcome-email behavior for licenses assigned through PowerShell or the Entra admin center.

  • Entra ID · Microsoft identity platform
    Teams and chat app consent gets new resource-specific controls

    Microsoft Entra ID and Microsoft Teams are introducing teams- and chat-specific consent settings for Team RSC and Chat RSC. The existing Group owner consent settings and API, along with the existing Chat RSC API, will be retired. The new settings are managed with Microsoft Graph PowerShell cmdlets, and Teams-level administrators can manage them independently. The rollout began taking effect on March 7 and is scheduled to reach all tenants by April 14. The notice describes a staged service change, not a preview or a

  • Entra ID · Developer
    Microsoft 365 admin-center user-consent control retires

    The User consent to Apps setting in the Microsoft 365 admin center will be retired in early April. This changes the administration surface rather than the policy itself: existing settings remain unchanged, but administrators will no longer be able to edit the tenant-wide policy there. The Entra portal is the replacement location, and the notice says no preparation is required.

  • Entra ID · Monitoring
    Entra PIM is in public preview in the Power Platform admin center

    The March notice announces public preview of Microsoft Entra Privileged Identity Management in the Power Platform admin center, while noting that the capability was already available there on February 5. It brings Entra PIM’s ability to manage, control, and monitor access into that administrative context. This is a preview announcement, not evidence of general availability or a new March launch.

  • Entra ID · Security
    Copilot welcome emails extend to licenses assigned outside the Microsoft 365 admin center

    During a late-March through late-April rollout, end users assigned Copilot for Microsoft 365 licenses through PowerShell or the Microsoft Entra admin center will automatically receive a welcome email when direct communications from Microsoft are enabled. Organizations can change communication preferences in the Microsoft 365 admin center, and individuals can change their own through security and privacy settings. This is a change in email behavior, not a reported licensing or provisioning migration.

For Entra administrators

Use the Entra portal for tenant-wide user-consent policy after the Microsoft 365 admin-center retirement; existing settings remain unchanged and no preparation is required for that transition. Teams administrators or automation that depend on the retiring consent settings or APIs should account for the new Microsoft Graph PowerShell-managed settings as rollout reaches all tenants by April 14. Treat the Power Platform PIM capability as preview. If Copilot licenses are assigned outside the Microsoft 365 admin center, organizations can adjust direct-communication preferences there, while individual users can change their own settings through security and privacy controls.

"User consent to apps" setting in the Microsoft 365 portal to be retired

New

The "User consent to Apps" setting in the Microsoft 365 Admin Center will be retired in early April 2024, and users are recommended to use the user consent settings in the Entra portal instead. No changes will be made to existing settings, but admins will no longer be able to edit the policy using the Microsoft 365 admin center. No preparation is needed, but users needing to view or edit their tenant-wide consent settings should use the experience in the Entra portal.

Microsoft Entra ID: New Microsoft teams-specific consent settings

New

Microsoft Entra and Teams are introducing new resource-specific consent settings for teams and chats to enhance secure app adoption. These settings will affect Chat RSC and Team RSC for apps in Microsoft Teams. Existing Group owner consent settings and API and the existing Chat RSC API will be retired with this update. The new settings will be managed using Microsoft Graph PowerShell commandlets and will start taking effect on March 7, 2024, and will completely roll out to all tenants by April 14, 2024. Teams-level admins can independently manage these settings. Instructions for modifying the new teams-specific consent settings can be found in the Configure consent settings section of Grant RSC permissions to an app - Teams | Microsoft Learn.
