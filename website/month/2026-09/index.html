Month in brief

Viva Engage role requirements tighten as Global Secure Access TLS guidance expands

September’s most consequential Entra developments were a late-month Viva Engage permissions change, a documented preview path for Microsoft-managed TLS inspection certificates in Global Secure Access, and an explicit 98% directory-quota threshold for managed identity creation. Microsoft also improved iOS Authenticator passkey restoration and revised the documented system-preferred authentication rollout through September 2026. Most other entries were documentation maintenance involving links, screenshots, examples, terminology, and troubleshooting guidance.

  • Entra ID · Security
    Viva Engage administration gains new Entra role requirements

    Starting in late September 2026, Viva Engage community and membership management tasks will require either the Microsoft Entra Yammer Administrator role or a Community Admin assignment. The new requirement replaces the prior Verified or Network Admin access path, so administrators should review assignments before the change.

  • Global Secure Access · Security
    Global Secure Access documents a preview path for Microsoft-managed TLS certificates

    A dedicated preview guide covers creating a tenant-specific Microsoft-managed root CA, deploying its public certificate to client devices, and enabling it for Microsoft Entra Internet Access TLS inspection. The private key remains protected by Microsoft; client deployment should precede enabling inspection to avoid certificate errors.

  • Workload ID · General
    Managed identity guidance sets a 98% directory-quota threshold

    The Managed Identities FAQ now states that creation is blocked when resulting directory usage reaches or exceeds 98% of the tenant quota. This applies to new and recreated service principals; existing identities and assignments continue to work, while soft-deleted objects count toward the quota. Reducing usage or increasing the quota enables retries.

  • Entra ID · Authentication
    Authenticator passkey restoration improves for iOS users

    The iOS Microsoft Authenticator app is rolling out a clearer, guided device-migration flow for restoring passkeys, worldwide in mid-September 2026. It affects users with iCloud backup, requires no administrator action, and does not change policy.

  • Entra ID · Authentication
    System-preferred authentication guidance extends deployment through September

    The Microsoft-managed system-preferred authentication article now places deployment through September 2026 instead of August 2026. Administrators should use the revised window when monitoring tenant and user behavior.

For Entra administrators

Review Viva Engage role assignments before late September: community and membership administrators will need the Yammer Administrator role or a Community Admin assignment. For Global Secure Access, deploy the Microsoft-managed root CA public certificate to client devices before enabling TLS inspection. Monitor tenant directory usage, including soft-deleted objects, before creating or recreating managed identities. Use the revised system-preferred rollout window when monitoring tenant and user behavior; the Authenticator passkey restore improvement requires no policy or administrator action.
