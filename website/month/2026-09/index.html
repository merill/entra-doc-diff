Month in brief

Passkeys become Entra’s default as Microsoft-provided SMS and voice authentication near retirement

September’s most consequential changes reshape Entra authentication. Passkeys became the default Microsoft Entra authentication on September 1, 2026, while Microsoft-provided SMS and voice authentication are scheduled to retire on February 1, 2027. Microsoft Graph also narrowed User.ReadBasic.All, while Enterprise State Roaming administration moved to Windows policies and new guidance covered External ID browser handoff and Global Secure Access TLS inspection.

  • Entra ID · Conditional Access
    Passkeys became the default as Microsoft SMS and voice authentication near retirement

    Passkeys became the default Microsoft Entra authentication on September 1, 2026. Microsoft-provided SMS and voice authentication will retire on February 1, 2027, after which customers must use telecom providers from the Microsoft Security Store. Microsoft recommends transitioning to passkeys for stronger, phishing-resistant security.

  • Entra ID · Microsoft identity platform
    User.ReadBasic.All lost access to app-role assignments and license details

    Starting in mid-September 2026, User.ReadBasic.All no longer provides access to user app role assignments and license details. Applications that need this data must use User.Read.All or LicenseAssignment.Read.All and update their permissions to avoid disruption.

  • Entra ID · General
    Enterprise State Roaming management moved out of the Entra admin center

    As of July 2026, administrators can no longer manage Enterprise State Roaming in the Microsoft Entra admin center. Windows settings backup and restore policies are now required for management; supported settings remain unchanged, and existing controls are honored for one year.

  • External ID · Authentication
    External ID can hand brokered identity-provider sign-in to the system browser

    The documented browser-authentication flow moves brokered external-identity-provider authentication from an embedded WebView to the system browser. This enables external-IdP passkeys, browser SSO, and providers that block WebViews. Adoption depends on the supported browser, broker, app versions, federation protocols, platforms, and cloud environments.

  • Global Secure Access · Security
    Global Secure Access previews Microsoft-managed certificates for TLS inspection

    The preview workflow creates a tenant-specific Microsoft-managed root CA for Microsoft Entra Internet Access TLS inspection. Administrators must deploy the public certificate to client devices before enabling inspection to prevent certificate errors; Microsoft protects the private key.

For Entra administrators

Plan to replace Microsoft-provided SMS and voice authentication with a telecom provider from the Microsoft Security Store before February 1, 2027, while moving users toward passkeys. Audit applications that rely on User.ReadBasic.All for app role assignments or license details and update them to User.Read.All or LicenseAssignment.Read.All as appropriate. Review ESR controls, validate External ID support prerequisites, and deploy the managed TLS root certificate to client devices before enabling TLS inspection.
