# Entra Scout (Scotty)

Discord avatar assets for the Entra documentation and Message Center update webhooks.

- `entra-scout-avatar-4096.png` — high-resolution transparent RGBA master.
- `entra-scout-avatar-1024.png` — Discord-ready transparent RGBA image.
- `entra-scout-avatar.svg` — path-based color vector trace with no embedded bitmap.

The artwork is padded for Discord's circular avatar crop. Use the 1024px PNG for Discord and retain the 4096px PNG and SVG as design masters.
